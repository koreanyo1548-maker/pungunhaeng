# 12명 기본탄 · 3단계 진화 원화

적용 대기 원본 `art/원본 이미지 대기/hero-projectiles-01~03-….png`를 직접 참조해 이미지 생성 도구로 게임용 투명 시트를 제작했습니다. 비교표의 글자·눈금·배경을 없애고 단계별 외곽·장식을 살렸습니다. 끝부분이 인접 행에 닿지 않도록 여백을 보정했습니다. 적용 대기 원본 PNG 3장은 그대로 보존합니다.

| 시트 | 행 순서 |
| --- | --- |
| evolution-01.png | 풍운객 검기 / 철혈 권기 / 묵영 암기 / 비천 어검 |
| evolution-02.png | 운학 깃털 / 홍련 비도 / 황연청 은침 / 목청완 창 |
| evolution-03.png | 매설영 채찍 / 한소운 쾌검 / 정요란 검기 / 아영 화살 |

각 행은 왼쪽부터 1·2·3단계입니다. 총 36종. 원본은 1536×1024 RGBA, 실행용은 변환 스크립트가 만든 1152×768 lossless WebP입니다. 알파가 0인 픽셀의 숨은 RGB 때문에 일부 이미지 뷰어에서 배경색이 보일 수 있으나, 브라우저에서는 투명 합성됩니다.

## 잘라 쓰는 기준

열 경계는 원본의 0·512·1024·1536px입니다. 행 경계는 **0·256·512·736·1024px**입니다. 마지막 행의 큰 창끝·검끝이 잘리지 않도록 736px부터 마지막 행으로 취급합니다. 실행용에서는 원본 대비 실제 축소 비율로 좌표를 계산합니다. 단순 256px 고정 행 자르기를 사용하지 않습니다.

로딩할 때 각 영역의 alpha 32 이상인 가시 영역을 측정하고 3px 여유를 더해 별도 캔버스 36개로 캐시합니다. 원본 이미지 파일을 코드로 자르거나 덮어쓰지 않습니다. 전투 중에는 픽셀을 검사하지 않습니다.

1단계 기준 표시 폭×높이(px): 풍운객 30×30, 철혈 28×32, 묵영 28×28, 비천 22×36, 운학 26×34, 홍련 22×34, 황연청 20×32, 목청완 24×38, 매설영·한소운·정요란 24×34, 아영 24×36. 2단계 1.16배, 3단계 1.32배입니다. 실제 충돌 판정과 독립적인 표시 값이며 `src/render/hero-shots.ts`에서 관리합니다.

묵영의 회전과 3단계의 짧은 잔상은 기존 동작을 따릅니다. 동작 줄이기에서는 이를 생략합니다. 영웅·단계는 발사 시점에 기록된 값을 사용합니다.

## 변환과 확인

새 원화를 추가할 때 `tools/mobile-image-profile.json`에 명시한 뒤:

```sh
python tools/convert-webp.py --bootstrap-new
npm run build
python tools/convert-webp.py
npm run build
python tools/convert-webp.py --check
node tests/e2e/hero-shot-art.mjs
```

`--bootstrap-new`는 아직 없는 실행용 파일만 인코딩해 첫 빌드의 입력을 만듭니다. 보고서와 좌표 메타데이터는 일반 변환 명령으로 생성합니다. 기존 파일의 인코딩 설정은 변경하지 않습니다. 새 원화의 full-size 비교 용량은 동일한 lossless 옵션으로 계산합니다.

검수 테스트는 실제 렌더러의 36종을 캡처해 `/workspace/artifacts/projectile-evolution-gallery.html`에 비교 페이지를 만듭니다. CI 스크린숏은 `SCREENSHOT_DIR` 아래에 저장합니다.
