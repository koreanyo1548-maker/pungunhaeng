# 화면 설명 문구 정리

사용자가 확인한 45개 문구 목록 기준:

- 유지: 6번 편대 선택 안내, 8번 눌러서 자세히 보기, 26~34번 저장 코드·장비·강화·인챈트 안내.
- 10번은 괄호와 안의 설명을 삭제하고 `지원형`만 유지.
- 삭제: 1~5, 7, 9, 11~25, 35~45번.

로비와 PC 장식 문구, 영웅/인연의 반복 설명, 뽑기 안내, 만남의 중복 설명과 각 스테이지 힌트를 제거한다. 삭제된 설명의 빈 문단·소제목·구분점도 남기지 않는다. 영웅/편대의 같은 역할 표기도 `지원형`으로 통일한다.

기술 효과와 수치, 비용, 실제 의뢰 목표·제한 시간·보상, 카운트다운, 정·사/만남 확률 수치, 게임 규칙은 유지한다. 26~34번이 있는 장비 화면 코드는 변경하지 않는다.

사용자 지시에 따라 테스트·브라우저·빌드·타입/형식 검사는 실행하지 않았다. 수정 파일의 포맷만 적용했다.
