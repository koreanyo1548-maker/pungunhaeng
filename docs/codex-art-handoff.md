# Codex 전달: 필요한 그림

Codex는 그림을 그리는 그래픽 디자이너다([작업 규칙](workflow.md) 7장). 이 문서는 Claude가 Codex에게 요청하는 그림 목록이다. 연출, 그림을 게임에 연결하는 일, 화면 표시는 Claude가 한다. 그림이 오기 전까지는 아래 "지금 대신 쓰는 것"으로 버틴다.

공통:

- 그림 방향과 검수 순서는 [풍운행 아트 스타일 기준](art-style-reference.md)을 따른다. 등급 식별, 상자·보석 재질, 실제 전투 크기 검수가 거기 있다.
- 화면은 480×800이고 크기는 그 기준 px이다. 원본은 `art/originals/`에 PNG로 두고 `python tools/convert-webp.py`로 WebP를 만든다(새 이미지는 `tools/mobile-image-profile.json`에 크기 결정을 추가).
- 그림이 들어오면 Claude가 게임에 연결한다. 프레임 수와 순서, 기준점(발 위치·중심)을 원본 파일 이름이나 PR 본문에 적어 준다.
- 이미 끝난 것: 자석·점수 두 배 드롭 아이콘(PR #31).

## 1. 적 등급 5·6

- **왜**: 판마다 등급 1~6을 순서대로 올라간다(등급 사다리, [판 밸런스 기준](balance-baseline.md)). 지금 적 그림은 4등급까지다.
- **지금 대신 쓰는 것**: 4등급 그림에 색을 입혀 5·6등급을 구분한다(5등급 붉은색, 6등급 보라색, `src/render/placeholder-art.ts`의 `tinted`).
- **필요한 그림**: 땅 스테이지 적 2종(`mobs.png`, 지금 4×2 아틀라스: 등급 4개 × 자세 2개)과 하늘 스테이지 적 2종(`sky-enemies.png`·`sky-enemies-motion.png`, 지금 3등급). 등급이 오를수록 더 위협적으로 보이게. 표시 크기는 지금 등급 크기(80·90·100·112px)를 이어 약 120·128px. 같은 아틀라스에 이어 붙이면 된다.

## 2. 보물상자 — 완료

전투용 닫힌 원화와 개봉 5프레임을 제작·연결했다. [전투 아이템 제작 기록](battle-item-art.md)을 따른다.

- **왜**: 줄의 한 칸에 드물게(판당 평균 2번) 섞여 나오는 특수 적. 강한 적만큼 단단하고, 터지면 엽전 20개가 쏟아진다.
- **현재 사용하는 것**: `battle-items.png`의 전투 상자 원화·개봉 프레임. 기존 코드 상자는 제거했다.
- **필요한 그림**: 평소 모습 1장, 터지는 프레임 4~6장(뚜껑이 열리며 빛이 터짐). 크기는 적 한 칸(약 90~100px). 맞을 때 흰 번쩍임은 코드로 만든다.

## 3-1. 듀얼샷 아이템 — 완료

산호색 바탕·금테·나란한 두 줄기의 전용 아이콘을 제작·연결했다. [전투 아이템 제작 기록](battle-item-art.md)을 따른다.

- **왜**: 새 판 안 아이템. 먹으면 3초 동안 기본 공격이 2줄로 나간다.
- **현재 사용하는 것**: `battle-items.png`의 듀얼샷 아이콘(56px). 기존 코드 아이콘은 제거했다.
- **필요한 그림**: 자석·점수 두 배 아이콘(56px)과 같은 틀의 아이콘 1장. 두 줄기 탄이 나란히 나가는 느낌, 산호색(#ff9a7a) 계열.

## 4. 무아지경 끝의 화면 폭발 (그림 시트, 선택)

- **왜**: 무아지경(기본 2초)이 끝날 때 화면 전체가 폭발하고 남은 적이 엽전으로 바뀐다. 연출은 Claude가 만들고, 그림 시트가 있으면 더 강해진다.
- **지금 대신 쓰는 것**: 화면 번쩍임, 흔들림, 큰 원형 파동(코드).
- **필요한 그림**: 밝은 섬광에서 번지는 폭발 시트 6~8프레임(약 480px 정사각, 투명 배경). 필요하면 영웅 주변 금빛 기운 시트.

## 5. 운석 경고 표식 (선택)

- **왜**: 운석이 평균 30초마다 2초 경고 뒤에 떨어진다. 경고선과 깜빡임은 Claude가 코드로 만든다.
- **필요한 그림**: 떨어질 자리 위쪽에 붙는 경고 표식 1장(약 48px, 붉은 "!" 느낌의 무협풍 표식).

## 6. 만남 등장 (선택)

- **왜**: 만남이 열리기 전 1.5초 동안 누가 오는지 알린다(인연 이름·계열, 행인 이름). 연출은 Claude가 만들고, 지금은 화면 위 글자 알림이다.
- **필요한 그림**: 쓸 수 있는 초상화는 이미 있다(인연 초상, 행인 초상). 등장 띠나 테두리 장식이 필요하면 따로 요청한다.

## 7. 정예 적과 장비 (2026-11, [장비와 루트 팩터 계획](equipment-plan.md))

장비 아이콘 15종과 빈 장착 칸 4종은 `gear.png` 시트로 제작·연결했다. 격자·초상화 주변 장착 칸·상세/강화/인챈트 팝업은 [장비 UI 제작 기록](gear-ui.md)을 따른다. 아래의 장비 아이콘 임시 그림 요청은 완료 상태다. 정예 적 원화는 계속 필요하다.

- **정예 적**: 한 판에 한 번 나오는 적. 크기는 일반 적과 같다(80~128px, 그 단계 적 크기). 날기(또는 걷기) 4프레임, 맞을 때 흰 실루엣. 크기가 같으니 생김새로 일반 적과 한눈에 구별되게(붉은 갑주의 무인 등). 지금 대신 쓰는 것: 붉은 5등급 적 그림을 그 크기로 쓰고, 아래에 붉은 후광과 체력 막대를 코드로 그린다(`render/elite-art.ts`).
- **장비 상자**: 완료. `gear.png` 4행 4열을 날아오는 상자와 결과 화면에 연결했다(2026-11).
- **장비 아이콘 15종**: 무기(청강검·쌍비수·관일창·연노), 의복(철포·운무의·호신갑), 장신구(혈옥환·호골낭·영물패·표국 영패), 비급(쌍희보·속사결·금강결·무아심법; 2026-11 이름 변경, 그림 그대로). 96×96, 배경 없이. 등급 테두리는 코드가 그린다. 지금 대신 쓰는 것: 칸마다 같은 모양(검·옷·패·책)을 색만 바꿔 코드로 그린다(`render/gear-art.ts`).
