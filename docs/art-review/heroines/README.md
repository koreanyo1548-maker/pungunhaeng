# 신규 여성 영웅 초상 수정 시안

`portraits-v2.png`: 기존 홍련 초상의 눈·피부 음영·색면을 기준으로 다시 그린 1536×1024, 3열×2행 시안. 순서는 황연청·목청완·매설영 / 한소운·정요란·아영.

사용자 피드백: 최초 초상은 매력이 부족하고 얼굴이 반복되며 성적인 매력과 기존 초상 스타일의 일관성이 부족함. 최초 세트의 제작 완료를 미적 승인으로 간주하지 않음.

수정 방향: 성인 여성의 관능미를 시선·입매·쇄골·어깨·옷깃과 실루엣에 반영. 얼굴형·눈·코·입 비율을 인물별로 구분하고 지나치게 조밀한 머리·복식 묘사를 줄임.

남은 검토: 황연청과 한소운 얼굴 유사성, 원본 대비 선과 질감의 차이. 이 시안은 확정 리소스가 아님. 의상 변경이 있어 채택 시 이동·시전 시트의 어깨와 옷깃도 맞춰야 함. 현재 게임 리소스와 갤러리는 최초 원화를 유지함.
