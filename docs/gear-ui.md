# 장비 UI와 아이콘

영웅 상세의 장비 탭은 초상화 양옆의 장착 칸(왼쪽 무기·의복, 오른쪽 장신구·비급), 효과 합계, 부위 필터와 4열 보관함으로 구성한다. 영웅의 긴 특성 설명은 레벨·성급 탭에서 확인한다. 장착 칸을 누르면 착용 장비 팝업, 빈칸을 누르면 해당 부위 보관함을 연다. 보관함은 등급·강화 내림차순이며 착용자를 표시한다.

상세 팝업은 기본 효과와 인챈트를 구분하고 현재 장비와 교체 시의 효과 증감을 표시한다. 장착·해제, 다른 영웅에게서 이동은 팝업 버튼으로 실행한다. 강화는 비용·소모될 실제 장비·전후 효과를 먼저 보여 주고 확정한다. 재료 자동 선택은 기존 규칙(미착용 동일 장비의 낮은 등급·강화 우선)이다. 인챈트는 미착용 재료 격자에서 하나를 고른 뒤 별도 확정한다. 기존 인챈트를 교체하며 선택 재료가 소모됨을 표시한다. 팝업의 닫기와 실행 버튼은 목록 스크롤 중에도 화면에 남는다. Escape는 장비 팝업부터 닫고 초점을 되돌린다.

저장 형식·장비 수치·비용·확률·게임 효과는 기존 규칙을 사용한다. UI와 연결은 이번 사용자 요청에 따라 Codex가 수행했다.

## 원화

`art/originals/gear.png`: 기존 `props.png`를 참조해 이미지 생성 도구로 제작한 투명 4열×5행 시트. 왼쪽 위부터 행 우선 순서:

1. 청강검, 쌍비수, 관일창, 연노
2. 철포, 운무의, 호신갑, 자석환
3. 금전낭, 영물패, 표국 영패, 쌍희보
4. 천리보, 정도결, 무아심법, 장비 상자(후속 연출용)
5. 빈 무기·의복·장신구·비급 실루엣

원본은 보존하고 `tools/convert-webp.py`로 런타임 시트를 50% 변환한다. 등급 테두리·별·강화·착용자 표시는 UI로 그린다. 15종 아이콘은 보관함·상세·뽑기·결과 화면에서 함께 사용한다.

## 검증

`CHROMIUM_PATH=/usr/bin/chromium node tests/e2e/gear-ui.mjs`: 360·390·1280px에서 격자, 비교, 강화 전후 재료·비용, 인챈트 선택/확정, 영웅 간 이동, 해제, 빈 보관함, Escape와 가로 넘침을 확인한다. 테스트 프로필은 별도 브라우저 컨텍스트 안에서만 만든다.
