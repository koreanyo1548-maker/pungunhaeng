# 전투 보물상자와 듀얼샷 원화

기존 `props.png` 아이템과 `gear.png` 장비 그림을 참조하여 이미지 생성 도구로 제작했다. 이번 작업은 전투 보물상자와 듀얼샷 두 종류만 교체한다.

- 원본: `art/originals/battle-items.png` (1774×887, 투명 4열×2행)
- 런타임: `src/assets/images/battle-items.webp` (50% 변환, 888×444)
- 행 우선 순서: 0 닫힌 상자, 1 잠금 해제, 2 반쯤 열림, 3 완전히 열림·빛, 4 빛·반짝임, 5 열린 상자·빛 소멸, 6 듀얼샷 아이콘, 7 빈칸.
- 프레임 경계는 `round(index × dimension / gridCount)`로 계산한다. 원본 PNG는 수정하지 않는다.
- 상자의 등록점은 셀 가로 50%·세로 62%. 모든 상자 프레임이 같은 바닥 위치를 사용한다.

전투 중 상자는 기존 크기(`e.size` 88px), 판정 반경 28, 체력 계산을 유지하고 새 닫힌 그림과 흰 피격 실루엣을 사용한다. 처치 후 기존 잔상(0.42초) 안에서 1~5 개봉 프레임을 재생한다. 잔상만 바뀌며 엽전은 기존 규칙대로 즉시 20개 떨어진다. 동작 줄이기에서는 열린 상자 한 프레임을 사용한다.

듀얼샷 셀은 바깥 여백을 10%씩 제외하고 다른 아이템과 같은 56px로 표시하며 기존 산호색 빛과 테두리를 사용한다. 획득 범위·낙하·발동 시간(기본 5초)·두 발 간격은 그대로다. 별도 장비 상자 그림은 변경하지 않는다.

로딩·표시는 `core/battle-item-art.ts`에서 명시적인 셀 번호로 연결한다. 두 종류의 기존 코드 임시 그림은 제거했고, `placeholder-art.ts`의 적 색 보정은 유지한다. 사용자 요청에 따라 Codex가 이번 표시 연결까지 수행했다.
