# 영웅별 체력과 전투불능

## 기본 규칙

- 각 영웅은 판을 시작할 때 현재 체력 1, 최대 체력 1로 시작한다. 영구 프로필과 성급 저장 형식은 바뀌지 않는다.
- 체력을 실제로 깎는 공격을 맞으면 체력 1이 감소한다. 체력이 남으면 같은 영웅으로 계속 싸운다.
- 체력이 0이 되면 해당 영웅은 전투불능이다. 생존한 대기 영웅이 있으면 같은 위치에 즉시 자동 출전한다. 없으면 패배 결과로 간다.
- 전투불능은 해당 판 동안 유지된다. 관문 회복, 회복 기술과 최대 체력 증가로 부활하지 않는다. 재도전은 새 판이므로 모두 다시 체력 1로 시작한다.

## 등장 (수동 교체 없음)

- 수동 교체는 없다(교체 버튼은 자리만 남기고 숨김, Q·Shift 키 없음). [능력 체계 개편 계획](ability-redesign-plan.md) 3장.
- 선봉이 쓰러지면 후발이 같은 위치에 바로 나선다. 들어온 영웅의 기존 체력을 사용하며 새로 회복시키지 않는다.
- 후발은 나서는 순간 등장 기술(n초 유지)을 시작한다. 풍운객은 쓰러진 선봉의 등장 기술을 대신 펼친다.
- 피격의 기존 보호 시간(1.9초)은 등장에도 이어진다. 같은 프레임에 여러 탄이나 적이 겹쳐도 두 영웅이 연달아 쓰러지지 않는다.

## 기존 기술·회복과의 관계

- 무적·무아지경은 기존대로 피해를 막는다. 불굴(철혈의 등장 기술)이 켜져 있으면 체력이 줄지 않는다. 철갑공 보호막과 회춘단도 먼저 소비되므로 이때는 체력 감소/사망/등장이 없다.
- 철혈의 특성(체력 +1)은 판 시작 때 그 영웅의 체력을 2로 만든다(★5는 3).
- 지닌 기술과 보호 효과는 기존처럼 편대가 공유한다. 철골은 살아 있는 편대원의 최대 체력을 +1 하고 즉시 1 회복한다. 전투불능 영웅의 체력은 0으로 유지한다. 철골을 잃으면 증가분을 되돌리고 남은 체력을 최대치로 제한한다.
- 회기, 객잔 회복과 관문 통과 회복은 현재 출전 영웅에게 적용한다. 생존한 영웅의 최대 체력 이상으로 회복하지 않으며, 전투불능 영웅을 되살리지 않는다.
- 공격력·발사체·인연 카드·의뢰·엽전 정산 규칙은 유지한다.

## 구조와 검증

`core/hero-health.ts`가 기본값·생존 판단·편대 체력 강화를 맡고, `RunState.heroHealth`가 판별 영웅 체력을 보관한다. `Player.hp/maxHp`는 출전 영웅을 가리키는 접근자이므로 표시/회복 코드에서 별도 체력 복사본을 관리하지 않는다. `formation.ts`의 `replaceFallenHero`가 후발의 등장을 처리한다.

`node tests/e2e/hero-lives.mjs`는 첫 사망 뒤 후발의 등장과 등장 기술, 전멸 패배/중복 정산 방지, 영웅별 체력 보존, 체력 강화/회복/소진, 기존 방어 효과, 실제 다중 위험물 충돌과 재시작을 검사한다. 기존 진행·저장·스킬·모바일 검사도 실행한다. 이번 변경은 게임 규칙 수정이므로 이전 체력 규칙과 결과가 같다는 회귀 검사를 적용하지 않는다.
