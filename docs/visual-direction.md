# 풍운행 화면 구성

전투 화면은 요청에 따라 직전 버전(기존 배경, 붉은 도형 적탄, 오른쪽 세로 버튼, 기존 HUD)으로 복원했다. 편대·돈오·투학 개선과 터치 입력 보정은 유지한다. 이후 승인받은 캐릭터 애니메이션·피격 효과만 추가하며 배치는 고정한다.

## 현재 확정 상태

- 전투 HUD, 버튼, 플레이 영역의 배치는 고정한다. 명시적인 요청 없이 옮기거나 크기를 바꾸지 않는다.
- 기존 배경, 오른쪽 세로 버튼, 기존 HUD를 사용한다. 적탄은 후속 승인에 따라 전용 이미지로 교체하되 붉은 위험 외곽과 기존 판정을 유지한다.
- 선택 화면은 짙은 먹색/청록 패널, 비급 종이색, 주홍 인장, 금색 확정 버튼을 공유한다.
- 편대는 초상화를 눌러 미리본 후 별도 버튼으로 확정한다. 돈오/투학은 카드 선택 즉시 확정한다.
- 터치 전투 버튼은 pointerdown에 반응하고 합성 click은 무시한다. 마우스와 키보드 click은 유지한다.

이미지 생성 도구로 이 프로젝트를 위해 제작했다.

- `src/assets/images/sky-enemies.png`: 비행 적 3종.
- `src/assets/images/title-journey.png`: 타이틀 배경.

기존 캐릭터 초상·전신·무공 아이콘은 재사용한다. 배경은 기존 루프 방식(교차 반전)으로 스크롤한다.

## 관문 표시 상자 (2단계 개편)

오른쪽 위 관문 표시 상자(`#stageHud`)는 자리와 크기를 그대로 두고 내용만 바꿨다. 굵은 줄은 `S1 산길 · 만남 62%`, 작은 줄은 `만남 2번 · 보스까지 3,200m`, 막대는 처치 게이지(다음 만남까지)다. 보스 경고부터는 막대를 비우고 `녹림 채주 출현`을 적는다. 필살기 버튼 테두리는 충전률 대신 남은 개수가 있으면 가득, 없으면 비운다(숫자는 그대로). 전투 배치 비교는 1단계 빌드와 3해상도 IDENTICAL.

## 검사

`npm test`: 타입 검사, 단일 파일 빌드, 스테이지·만남·보스·결과 흐름 E2E(시나리오 A~G).

`npm run test:ui`: 빌드된 단일 파일에서 360×640, 390×844, 1280×900 화면의 스테이지 선택, 편대 미리보기/확정, 터치 드래그, 숨긴 교체 자리, 필살기 단일 사용, 만남 선택을 검사한다. 먼저 `npm run build:single`을 실행한다.

`SCREENSHOT_DIR=/tmp/pungunhaeng-ui npm run test:ui`로 화면 캡처를 저장할 수 있다.

## 전투 애니메이션 1차

- 기본 공격 동작: 모든 영웅이 같은 방식이다. 몸은 달리기(땅)·비행(하늘) 그림을 유지하고, 공격마다 휘두름 궤적을, 3번에 한 번 베기 이펙트를 띄운다. 풍운객만 따로 쓰던 4프레임 공격 자세는 다른 영웅과 맞지 않아 뺐다(`pungun-attack.png` 삭제).
- 비행 적 3종: 각 4프레임으로 자세와 옷자락을 움직인다. 피격 시 흰색 실루엣과 반동을 사용한다.
- 일반 적은 짧은 베임, 장갑 적은 불꽃, 바위는 파편으로 접촉 효과를 구분한다. 보스 격파 연출은 유지한다.
- 격파 잔상은 죽는 순간의 그림을 저장하여 사용한다. 하늘 적이 지상 그림으로 바뀌는 문제를 수정한다.
- 동작 줄이기 설정에서는 공격/비행 프레임을 고정하고 접촉 효과의 이동량을 줄인다.
- 신규 생성 이미지: `sky-enemies-motion.png`. 기존 원화를 참조하여 프로젝트 전용으로 생성했다.

검증: 타입 검사, 일반/단일 HTML 빌드, 기존 흐름·모바일 UI E2E. 이전 HTML과 두 코스의 동일 시드 입력(각 600스텝)을 비교해 게임 상태가 일치함을 확인했다. `tests/equivalence/combat-layout.mjs <이전.html> <이후.html>`은 360×640, 480×800, 1280×900에서 일반 전투/보스전 HUD와 버튼의 위치·크기를 비교한다.

## 심마 전용 원화

`src/assets/images/simma.png`는 별도로 생성한 심마 전용 3포즈(대기·공격 준비·내려베기) 투명 스프라이트다. 기존 영웅에 보라색을 입히던 방식을 제거했다. 보스 등장, 전투, 피격 실루엣, 돌진 잔상, 격파 잔상이 같은 전용 프레임을 사용한다. 기존 보스 크기, 판정과 공격 타이밍은 유지한다.

## 발사체·위험물 이미지

- 죽창은 기존 `props.png`의 죽창 원화, 바람 칼날은 `projectile.png`의 곡선 날을 사용한다. 낙하물은 새 균열 암석 이미지다.
- 보스별 탄: 녹림 채주 도끼날, 철갑 권승 금강 구슬, 천마 교주 붉은 마검, 심마 보라 결정. 인연 방해탄은 붉은 부적이다. 보스 주변 장식 검도 기존 검 이미지로 교체한다.
- `combat-projectiles.png`: 프로젝트 전용 생성 이미지 8칸(보스 탄 4종·낙하석·만천화우 비도·검우 검·천마군림 검강).
- 만천화우는 꽃잎형 비도, 짧은 발사 부채와 잔상을 사용한다. 녹림도법은 주황 도기로 구분한다. 검우는 여러 은청색 검, 천마군림은 단일 금빛 검과 즉시 표시되는 수직 공격선이다.
- 탄 개수·속도·궤적·충돌 반경·피해·쿨다운은 유지한다. `art` 필드는 렌더링에만 사용한다. 드롭 아이템은 기존 이미지가 이미 연결돼 있어 유지한다.
- 동일 입력 회귀 검사에는 `EQUIP_SKILLS=mancheon,geomu,art_cheonma,art_dobeop`을 지정해 관련 스킬을 장착할 수 있다.

## 픽셀 이펙트 (pixelfx)

- 타격·처치·피격·방어·회복·획득·교대·내공 해방·보스 격노·보스 처치의 파티클·링·섬광을 pixelfx(MIT, `src/vendor/pixelfx`) 실시간 이펙트로 교체했다. 일러스트 효과(`paintFX`), 한글 글자, 보스 등장·배너, 발사체 이미지는 그대로다.
- 크기는 화면 1배(적 크기와 같은 비율), 내공 해방·보스 격노·보스 처치만 2배.
- 효과 전용 난수(`fxRandom`)만 쓰며 게임 판정·타이밍·화면 흔들림 수치는 바꾸지 않았다. 동작 줄이기 설정이나 URL `#legacyfx`에서는 기존 효과를 그린다.
- 자세한 대응표, 성능 측정, 검증은 `docs/pixelfx-plan.md` 0장.

## 전체 기술 애니메이션 1차

24개 기술의 전용 이미지 시퀀스, 6종 발사체 반복 프레임과 6명 교체 자세를 추가했다. 제작 목록·프레임 구성·검토 범위는 [기술 이미지 애니메이션 제작 기록](skill-animation-production.md)을 따른다. 전투 배치와 규칙은 유지하며, pixelfx는 공용 보조 효과로 남긴다.

## 기술 등급과 초식 이름

기술을 얻거나 강화했을 때 무엇이 강해졌는지 바로 알 수 있게, 등급(★/★★), 세 줄 카드 문구(발동·효과·★★ 강화), 초식 이름 표시, 더 크고 강한 기술 발사체를 넣었다. 표기 규칙과 위력 수치는 [화면 용어](terms.md)의 "기술 표기"를 따른다. 전투 HUD의 위치와 크기는 그대로이고, 기술 아이콘에는 테두리와 별만 더했다.

## 화면을 덮는 기술 연출

필살기와 검우, 천마군림처럼 화면 전체에 걸치는 기술은 크기와 시간을 그 무게에 맞춘다. 판정과 지속 시간 같은 게임 규칙은 그대로이고, 아래는 표시만 바꾼 것이다.

- 필살기: 기술 원화 6프레임 전체를 화면 폭 크기(460px)로 0.85초 재생하고(`skillBurst`), 화면 전체에 옥색 빛이 퍼졌다 사라진다(`screenWash`). 이전에는 240px로 0.24초였다.
- 검우: 비가 내리는 1.5초 동안 화면 전체에 검이 쏟아지는 층을 그린다(`drawSwordRain`, 시간으로만 계산해 난수를 쓰지 않음). 적을 맞히는 낙검은 230px로 0.6초 보인다(이전 150px, 0.32초).
- 천마군림 낙검: 300px로 0.55초 보인다(이전 220px, 0.32초).
- 동작 줄이기에서는 화면 빛을 40%로 약하게, 쏟아지는 검을 절반 수로 느리게 그린다.

## 타이틀 화면 (로비)

타이틀을 게임 로비처럼 다시 짰다. 전투 화면과 선택 화면은 건드리지 않았다.

- 위쪽 줄: 왼쪽에 지닌 엽전(엽전 그림 + 금액), 오른쪽에 소리 버튼.
- 가운데: 제목과 풍운객 흉상. 흉상 아래쪽은 안개 속으로 흐려지게 해서 잘린 가장자리가 보이지 않는다.
- 아래쪽: 최고 기록, "강호에 나서기" 버튼(빛이 지나가는 효과), 조작 안내 한 줄.
- 메뉴 세 칸: 영웅(합류한 수), 인연(카드를 가진 수), 뽑기. 한 번이라도 뽑을 엽전이 있으면 뽑기 칸에 붉은 점과 "뽑기 가능"이 뜬다(`ui/hud.ts`의 `showBank`).
- 동작 줄이기에서는 안개, 검빛, 버튼 빛, 붉은 점의 움직임을 끈다.

## 수동 교체 제거와 등장 기술 표시

- 수동 교체가 없어져 오른쪽 버튼 줄의 교체 버튼은 **자리만 남기고 숨긴다**(`slot-kept`, 보이지 않고 누를 수 없음). 그래서 필살기 버튼은 그대로이고, 전투 배치 비교(`combat-layout.mjs`)는 이전 빌드와 같다.
- 후발이 등장하면 교체 자세를 그대로 쓰고, 등장 기술이 켜져 있는 동안 발밑에 줄어드는 고리를 그린다. 학의 장막(원), 정심반사(반달 검막), 그림자 분신(반투명 분신), 어검진(도는 비검)은 도형과 기존 원화로 그린다(`render/hero-effects.ts`).

## 위험물·줍기 강조 효과

중요한 판 안 요소 뒤에 pixelfx 반복 효과를 붙여 강조한다(`src/render/glows.ts`). 효과는 스테이지가 시작할 때 한 번 프레임 그림으로 만들어 두고, 플레이 중에는 그림만 그린다(죽창이 많아도 가볍다). 색과 빛을 검은 바탕에 합쳐 'lighter'로 더하므로 뒤 배경에 빛이 얹힌다. 동작 줄이기 설정이나 `#legacyfx`에서는 그리지 않는다.

- 죽창: 그림 1.25배, 뒤에 옥색 레이저 꼬리(`projectiles/laser-bolt`, 1.15배 시안). 바람 칼날(운해)은 그대로.
- 운석: 그림 1.25배, 뒤에 불꼬리(`fire/fireball`).
- 엽전: 효과 없음. 금빛 빛살을 붙였다가 많이 떨어질 때 정신 사나워 뺐다.
- 아이템: 뒤에 빛살(`holy/sunburst`). 무아지경 하늘색, 자석 옥색, 점수 두 배 금색.
- 맞는 판정(죽창 반지름 8, 운석 23)은 그대로다. 그림만 커졌다.
