# 풍운행 화면 구성

전투 화면은 요청에 따라 직전 버전(기존 배경, 붉은 도형 적탄, 오른쪽 세로 버튼, 기존 HUD)으로 복원했다. 편대·돈오·투학 개선과 터치 입력 보정은 유지한다. 이후 승인받은 캐릭터 애니메이션·피격 효과만 추가하며 배치는 고정한다.

## 현재 확정 상태

- 전투 HUD, 버튼, 플레이 영역의 배치는 고정한다. 명시적인 요청 없이 옮기거나 크기를 바꾸지 않는다.
- 기존 배경, 오른쪽 세로 버튼, 기존 HUD를 사용한다. 적탄은 후속 승인에 따라 전용 이미지로 교체하되 붉은 위험 외곽과 기존 판정을 유지한다.
- 선택 화면은 짙은 먹색/청록 패널, 비급 종이색, 주홍 인장, 금색 확정 버튼을 공유한다.
- 편대는 초상화를 눌러 미리본 후 별도 버튼으로 확정한다. 돈오/투학은 카드 선택 즉시 확정한다.
- 터치 전투 버튼은 pointerdown에 반응하고 합성 click은 무시한다. 마우스와 키보드 click은 유지한다.

기존 캐릭터 초상·전신·무공 아이콘은 재사용한다. 배경은 기존 루프 방식(교차 반전)으로 스크롤한다.

## 검사

`npm test`: 타입 검사, 단일 파일 빌드, 두 코스 완주/분기/사망 E2E.

`npm run test:ui`: 빌드된 단일 파일에서 360×640, 390×844, 1280×900 화면의 미리보기/확정, 터치 드래그, 교대, 내공 단일 사용, 돈오 선택을 검사한다. 먼저 `npm run build:single`을 실행한다.

`SCREENSHOT_DIR=/tmp/pungunhaeng-ui npm run test:ui`로 화면 캡처를 저장할 수 있다.

## 전투 애니메이션 1차

- 풍운객 기본 공격: 준비·베기·후속 동작·회수 4프레임. 기존 발사/스윙 시계에 맞춰 표시하며 공격 주기와 판정은 그대로 유지한다.
- 비행 적 3종: 각 4프레임으로 자세와 옷자락을 움직인다. 피격 시 흰색 실루엣과 반동을 사용한다.
- 일반 적은 짧은 베임, 장갑 적은 불꽃, 바위는 파편으로 접촉 효과를 구분한다. 보스 격파 연출은 유지한다.
- 격파 잔상은 죽는 순간의 그림을 저장하여 사용한다. 하늘 적이 지상 그림으로 바뀌는 문제를 수정한다.
- 동작 줄이기 설정에서는 공격/비행 프레임을 고정하고 접촉 효과의 이동량을 줄인다.
- 신규 생성 이미지: `pungun-attack.png`, `sky-enemies-motion.png`. 기존 원화를 참조하여 프로젝트 전용으로 생성했다.

검증: 타입 검사, 일반/단일 HTML 빌드, 기존 흐름·모바일 UI E2E. 이전 HTML과 두 코스의 동일 시드 입력(각 600스텝)을 비교해 게임 상태가 일치함을 확인했다. `tests/equivalence/combat-layout.mjs <이전.html> <이후.html>`은 360×640, 480×800, 1280×900에서 일반 전투/보스전 HUD와 버튼의 위치·크기를 비교한다.

## 심마 전용 원화

`src/assets/images/simma.png`는 별도로 생성한 심마 전용 3포즈(대기·공격 준비·내려베기) 투명 스프라이트다. 기존 영웅에 보라색을 입히던 방식을 제거했다. 보스 등장, 전투, 피격 실루엣, 돌진 잔상, 격파 잔상이 같은 전용 프레임을 사용한다. 기존 보스 크기, 판정과 공격 타이밍은 유지한다.

## 발사체·위험물 이미지

- 죽창은 기존 `props.png`의 죽창 원화, 바람 칼날은 `projectile.png`의 곡선 날을 사용한다. 낙하물은 새 균열 암석 이미지다.
- 보스별 탄: 녹림 채주 도끼날, 철갑 권승 금강 구슬, 천마 교주 붉은 마검, 심마 보라 결정. 인연 방해탄은 붉은 부적이다. 보스 주변 장식 검도 기존 검 이미지로 교체한다.
- `combat-projectiles.png`: 프로젝트 전용 생성 이미지 8칸(보스 탄 4종·낙하석·만천화우 비도·검우 검·천마군림 검강).
- 만천화우는 꽃잎형 비도, 짧은 발사 부채와 잔상을 사용한다. 녹림도법은 주황 도기로 구분한다. 검우는 여러 은청색 검, 천마군림은 단일 금빛 검과 즉시 표시되는 수직 공격선이다.
- 탄 개수·속도·궤적·충돌 반경·피해·쿨다운은 유지한다. `art` 필드는 렌더링에만 사용한다. 드롭 아이템은 기존 이미지가 이미 연결돼 있어 유지한다.
- 동일 입력 회귀 검사에는 `EQUIP_SKILLS=mancheon,geomu,art_cheonma,art_dobeop`을 지정해 관련 스킬을 장착할 수 있다.

## 픽셀 이펙트 (pixelfx)

- 타격·처치·피격·방어·회복·획득·교대·내공 해방·보스 격노·보스 처치의 파티클·링·섬광을 pixelfx(MIT, `src/vendor/pixelfx`) 실시간 이펙트로 교체했다. 일러스트 효과(`paintFX`), 한글 글자, 보스 등장·배너, 발사체 이미지는 그대로다.
- 크기는 화면 1배(적 크기와 같은 비율), 내공 해방·보스 격노·보스 처치만 2배.
- 효과 전용 난수(`fxRandom`)만 쓰며 게임 판정·타이밍·화면 흔들림 수치는 바꾸지 않았다. 동작 줄이기 설정이나 URL `#legacyfx`에서는 기존 효과를 그린다.
- 자세한 대응표, 성능 측정, 검증은 `docs/pixelfx-plan.md` 0장.

## 전체 기술 애니메이션 1차

24개 기술의 전용 이미지 시퀀스, 6종 발사체 반복 프레임과 6명 교체 자세를 추가했다. 제작 목록·프레임 구성·검토 범위는 [기술 이미지 애니메이션 제작 기록](skill-animation-production.md)을 따른다. 전투 배치와 규칙은 유지하며, pixelfx는 공용 보조 효과로 남긴다.
