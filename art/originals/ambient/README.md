# 일반 NPC·객잔·수집 원화

기존 `npc-portraits.png`와 `props.png`를 참조하여 이미지 생성 도구로 새로 제작한 PNG 리소스다. 먹선, 따뜻한 피부색, 천·나무·청동 질감을 기존 원화에 맞췄다. 모두 알파 투명 배경이다.

`core/ambient-art.ts`가 `catalog.json`의 실제 칸 크기로 시트를 잘라 로딩한다. 일반 NPC 만남에는 기본 초상, 베푼 직후 기존 알림에는 감사 초상을 표시한다. 객잔 상품 3종과 뽑기 결과의 조각 종류에도 연결했다. 등장 순서·가격·덕·보상 규칙은 유지한다. 길 잃은 아이는 원화와 연결 정보가 준비돼 있지만 현재 일반 관문 3개/최종 관문 구조에서는 정상 진행에 등장하지 않는다.

## NPC 초상

`passers-neutral.png`와 `passers-grateful.png`: 각각 **1254×1254, 2열×2행, 칸당 627×627**. 두 시트의 인물 순서는 같다. 기존 인연 초상의 칸은 512×512이지만, 새 시트를 자를 때는 실제 627×627 크기를 사용하고 화면에서는 기존 초상 표시 크기를 따른다.

| 열·행 (0부터) | ID | 인물·소품 |
|---|---|---|
| 0·0 | market-woman | 아낙네, 머릿수건·장바구니 |
| 1·0 | wanderer | 떠돌이 행인, 봇짐·지팡이 |
| 0·1 | woodcutter | 늙은 나무꾼, 나뭇짐·도끼 |
| 1·1 | lost-child | 길 잃은 아이, 작은 보따리 |

neutral은 만남의 걱정·피로 표정, grateful은 같은 얼굴·복식의 감사·안도 표정이다. 전신 스프라이트나 애니메이션 프레임이 아닌 반신 초상이다. 허리선이 끝나는 구도이므로 전신으로 확대 사용하지 않는다.

## 객잔·조각 아이콘

`inn-collection.png`: **1536×1024, 3열×2행, 칸당 512×512**. 기존 `props.png`와 시트/칸 크기가 같다. 마지막 칸은 비워 두었다.

| 열·행 (0부터) | ID | 내용 |
|---|---|---|
| 0·0 | inn-rest | 약주와 휴식: 주병·술잔·만두를 담은 나무 쟁반 |
| 1·0 | inn-pill | 필살 단약: 붉은 안감의 단약함 |
| 2·0 | inn-meditation | 명상: 청동 향로와 가는 연기 |
| 0·1 | hero-piece | 영웅 조각: 검 문양의 부러진 금빛 패와 붉은 술 |
| 1·1 | bond-piece | 인연 조각: 매듭 장식이 달린 깨진 옥빛 카드 |

얼굴 초상은 기존 인연과 같은 비중으로, 아이콘은 작은 표시 크기에서 종류가 구분되도록 대표 소품 중심으로 제작했다. 실제 게임 연결 시 초상/아이콘 표시 크기와 밝은/어두운 배경에서 최종 확인한다.
