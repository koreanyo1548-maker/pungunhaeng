# 공명 계획

2026-11-28. 인연을 대신하는 판 안 성장 축이다. 세계관(주인공이 딸들의 과열된 권능을 가져간다)은 [세계관과 설정](world-setting.md)을 따른다. 이 문서는 게임 규칙만 적는다.

## 1. 바뀐 것

| 이전 | 지금 |

## 2. 흐름: 조짐 → 달성 → 공명

- 공명은 명령할 수 없다. 딸의 권능과 주인공이 품은 권능이 같은 결로 떨릴 때만 넘어온다. 주인공은 그 결이 어디서 생기는지 읽는다. 그것이 **공명의 조짐**이다.
- 조짐은 조건 하나다(`systems/quest.ts` `SIGNS`).

| 조건 | 화면 문구 | 전체 수 |
|---|---|---|
| 스침 | 적의 곁을 스쳐라 | 24 |
| 좌우 전환 | 좌우로 빠르게 움직여라 | 90 |
| 근접 처치 | 가까이서 베어라 | 12 |
| 한 줄 전멸 | 한 줄을 쓸어버려라 | 4 |
| 연속 처치 | 끊김 없이 베어라 | 40 |

- 목표는 전체 수의 5/6 ±10%(정요란 특성이 줄인다). 바로 앞 조짐과 같은 조건은 나오지 않는다.
- **시간**(`BASELINE.meet`, 만남 때와 같음)
  - 첫 조짐은 스테이지가 열리자마자 온다(이전 만남은 비행 10초 뒤). 알림 없이 바로 카드가 열린다.
  - 조짐마다 비행 60초. 넘기면 흩어지고 3초 뒤 다음 조짐이 알림(1.5초, 싸움은 계속) 뒤에 열린다.
  - 이루면 다음 안전한 순간에 공명 화면이 열린다. 고른 뒤 4.4초(1.4 + 3) 뒤 다음 조짐 알림.
  - 경고·보스전에서는 시간이 멈춘다. 경고 때 진행 중인 조짐은 보스전으로 이어지고, 보스전에서 이루면 공명 화면이 그 자리에서 열린다. 보스전에는 새 조짐이 오지 않는다.
  - 무아지경 중에는 조짐이 세지 않는다.
- **카드**: 조짐 카드 한 장(조건, 목표, 60초). 화면을 누르면 받고, 10초가 지나면 저절로 받는다.
- **공명 화면**: 공명 기술 셋(새 기술 또는 가진 기술의 다음 레벨). 하나를 누르면 바로 배운다. 카운트다운은 없다(고르는 일이라서).

## 3. 공명 기술

- 10개(`data/skills.ts`). 한 판에 **3칸**, 기술마다 **Lv 3**까지. 칸이 다 차면 가진 기술의 다음 레벨만 나온다. 모두 Lv 3이면 더 줄 것이 없어 조짐이 오지 않는다.
- 후보 셋은 게임 RNG로 고른다(같은 시드면 같은 후보).
- 레벨마다 한 방향으로만 자란다(발사체, 공격력, 범위, 쿨타임, 지속 시간).
- 수치는 모두 **임시**다. 균형은 사용자의 플레이로 맞춘다([작업 규칙](workflow.md) 8장). D는 기본탄 한 발 피해.

| 기술 | 발동 | 자라는 방향 | Lv 1 → 2 → 3 | 위력 |
|---|---|---|---|---|
| 기탄 | 1초마다 추적 기탄 | 발사체 | 2발 → 3발 → 4발 | 2D |
| 태극운검 | 스칠 때 추적탄 (0.6초에 한 번) | 공격력 | 4D → 6D → 8D | |
| 녹림도법 | 1.2초마다 부채꼴 도기 | 발사체 | 5방향 → 7방향 → 9방향 | 1.7D |
| 잔영검 | 좌우로 움직일 때 검기 (0.6초에 한 번) | 발사체 | 2발 → 3발 → 4발 | 2D |
| 붕산권 | 근접 처치한 자리에 충격파 | 범위 | 반경 80 → 100 → 120 | 5D |
| 천마군림 | 가장 강한 적의 세로줄에 검강 | 쿨타임 | 3초 → 2초 → 1.5초 | 9D |
| 어검진 | 비검이 주위(반경 62)를 돌며 닿는 적을 벤다 | 발사체 | 3자루 → 4자루 → 5자루 | 1.4D (같은 적은 0.22초에 한 번) |
| 홍련화 | 12초 중 일부 동안 모든 공격이 치명타 (피해 2배) | 지속 시간 | 6초 → 9초 → 늘 | |
| 그림자 분신 | 10초 중 일부 동안 분신 둘이 기본 공격을 따라 쏜다 | 지속 시간 | 5초 → 7.5초 → 늘 | |
| 관창 | 정면으로 관통 창 | 쿨타임 | 1.2초 → 0.8초 → 0.6초 | 4.8D |

- 바뀐 점
  - 태극운검: 적이 쏘지 않으니 "스친 탄을 되돌림"을 "스칠 때 추적탄"으로 바꿨다.
  - 어검진: 탄을 막던 부분은 뺐다. 판 내내 돈다(등장 기술 때는 20초).
  - 홍련화·그림자 분신: 한 번 켜지던 등장 기술을 주기마다 다시 켜지게 했다. 시계는 싸우는 동안만 간다.
  - 관창: 등장 기술 때(10D, 0.6초)는 기본 공격의 두 배를 넘어 크게 낮췄다.
- 화면: 전투 중 기술 칸에 아이콘과 레벨 숫자. 기술이 실제로 터질 때(홍련화·분신은 켜져 있는 동안) 칸이 빛난다. 초식 이름은 이전 인연 기술처럼 찍힌다.
- 그림: 이전 인연 기술과 등장 기술의 그림을 그대로 쓴다. 조짐 아이콘과 새로 생긴 넷의 아이콘은 가까운 그림을 빌렸다([Codex 전달](codex-art-handoff.md)).

## 4. 아직 하지 않은 것

- **보조와 진화**: 보조(공격력, 스침 범위, 엽전 드랍량, 최종 점수 등)와 "Lv 3 + 짝 보조 → 진화"는 다음 단계다.
- **균형**: 초당 피해를 맞추는 일은 플레이 뒤에 한다. 계산상 지금은 기술마다 차이가 크다(관창·녹림도법이 강하고, 붕산권·어검진은 줄이 지나간 뒤에야 닿아 약하다).
- **필살기 다양화와 폭주 게이지**: 공명 다음 작업.

## 5. 연결을 끊은 것

코드는 남기고 주석에 메모했다. 다시 쓸 때 이 목록에서 시작한다.

| 무엇 | 지금 상태 | 자리 |
|---|---|---|
| 인연 화면 | 타이틀의 인연 칸을 숨겼고, `main.ts`가 화면을 불러오지 않는다 | `index.html`, `src/scenes/cards.ts` |
| 인연 호감도 | 저장에는 남지만 아무것도 올리거나 읽지 않는다 | `core/profile.ts` `bonds`, `addBond` |
| 인연 카드 등급 | 판 시작 스냅샷에는 들어가지만 읽는 곳이 없다 | `data/meta.ts` `Meta.cards` |
| 인연 데이터 | 초상화와 함께 남김. `levels`에 옛 기술 id | `data/npcs.ts` |
| 행인 그림 | 쓰이지 않는다 | `core/ambient-art.ts` |
| 정도 점수 보너스 팩터 | 장비가 주지 않는 판 전체 팩터라 지금은 아무 효과가 없다 | `data/factors.ts` `virtueScorePct` |
| 최종 관문(심마) | 흐름 밖. 인연 대신 공명 기술을 보여 준다 | `scenes/final-gate.ts` |

지운 것: 정·사(`systems/alignment.ts`), 행인 의뢰(`systems/virtue.ts`), 인연 단계(`systems/relationship.ts`), 인연 기술 중 공명 기술이 되지 않은 여섯(회춘단·유수파·철갑공·만천화우·의협난도·검우)과 그 화면 효과(보호막, 회춘단, 검의 비), 등장 기술과 그 그림(결계·반사·시간 고리), 편대 교체.

## 6. 작업 기록 · 2026-11-28

이날 사용자와 나눈 설계 대화와 구현(PR #66)을 적는다.

### 설계 결정

1. **방향**: 게임에 도파민이 부족하고 힘이 억제된 느낌이라는 문제에서 시작했다.
   - 기본 공격의 성장 축은 메타(장비·레벨)에 둔다.
   - 판 안의 휘발성 성장은 주인공의 개입인 공명이 맡고, 화려한 발사체의 연속과 강화로 보여 준다.
   - 필살기는 영웅마다 다양하게 한다(광역, 타임 스톱, 골드 생성, 유도 다발). 공명 다음 작업이다.
   - 폭주는 권능을 쓸수록 차는 게이지로, 제어할 수 없게 터진다. 무아지경을 대신한다.
2. **편대 비행 제거**: 한 판에 영웅 한 명. 편대가 없으니 등장 기술도 필요 없다.
3. **공명의 개연성**: 퀘스트를 왜 주는지 설명이 필요했다. 주인공이 권능의 결을 읽는 "공명의 조짐"으로 풀었다. 정·사 축은 없앴다. 흐름은 조짐 → 달성 → 보상이다.
4. **기술 성장 방식**: 단계마다 다른 기술이 아니라 같은 기술이 강해진다. 공명할 때마다 고른다.
   - 로그라이크 틀: 기술 + 보조 + 진화 + 칸 제한을 쓰기로 했다. 시너지 태그, 희귀도, 새로고침은 나중이다.
   - 정한 값: 기술 3칸, 보조 2칸, 기술 3단계, 후보 3개, 보조는 단계 없음, 진화는 Lv 3 + 짝 보조를 갖추는 순간 바로.
   - 공명 주기는 지금 그대로 두되, 첫 조짐만 10초 대기 없이 바로 준다. 줄 것이 없으면 조짐이 오지 않는다.
5. **버린 안**: 같은 실수를 되풀이하지 않도록 이유를 남긴다.
   - **일반 슈팅식 기술**(추적탄, 360도 고리, 적 탄 제거, 광선, 맞은 적이 엽전을 떨어뜨림): 우리 인플레이와 맞지 않았다.
     - 우리 인플레이는 DF식이다. 5칸 줄이 내려오고, 적은 쏘지 않으며, 체력은 맞은 발 수로 정해진다. 핵심은 내 앞 칸을 뚫는 것이다.
     - 처치하면 엽전은 원래 나온다.
   - **사건마다 붙는 추가 공격**(스침, 근접 처치, 엽전 획득, 일반 공격, 한 줄 전멸): 조건이 빡빡하고 레벨 성질이 섞여 직관적이지 않았다.
   - **한 줄 전멸 발동 기술**: 막힐 때는 터지지 않고 이미 잘 풀릴 때만 터진다. 다음 줄은 아직 화면에 없을 때가 많다. 기술 발동에서 뺐다(조짐 조건에는 남아 있다).
   - **보조 안 두 가지**(관통·발사체 수·연사 / 사건 반응형): 메타 팩터와 겹치거나 방향이 맞지 않았다. 보조는 다음에 다시 정한다.
6. **확정된 기술 10개**
   - 이미 있는 기술에서 골랐다: 기탄, 태극운검, 녹림도법, 잔영검, 붕산권, 천마군림(인연 기술), 어검진, 홍련화(등장 기술), 그림자 분신, 관창(숨긴 영웅의 등장 기술).
   - 각자 한 방향(범위, 발사체, 공격력, 쿨타임, 지속 시간)으로 3단계까지 자란다.
   - 진화는 공격력이나 범위를 크게 올리는 쪽으로 한다(아직 만들지 않음).
7. **균형**: 초당 피해 계산안을 냈다(기본 공격 초당 8D 기준으로 Lv1 4 → Lv2 6 → Lv3 8 → 진화 16). 사용자가 균형은 나중에 하기로 했다. 지금 수치는 제안 방향에 넣은 임시값이다.
8. **인연 메타**: 이번에는 연결만 끊었다(5장). 딸들과 주인공 사이의 관계로 다시 짤 때 쓴다.

### 구현 (PR #66)

- 바뀐 것은 1~3장과 5장에 적었다.
- 테스트
  - e2e 전체 흐름(`tests/e2e/run-all.mjs`)과 수동 테스트 8개를 새 규칙에 맞춰 통과시켰다: `hero-kit`, `hero-lives`, `skill-art`, `encounter-ui`, `mobile-ui`, `ambient-art`, `refactor-regressions`, `gear-ui`.
  - 전투 화면 배치는 main과 같다(`combat-layout`).
- 돌리지 못한 것
  - `webp-assets`: WebKit이 없는 환경이다.
  - `mobile-image-geometry`: 비교용 이전 빌드가 필요하다.
