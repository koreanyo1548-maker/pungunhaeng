# 여성 영웅 6명 · 연결된 리소스

최신 초상과 같은 머리색·복식으로 이동·시전 시트를 다시 그렸습니다. 기존 초상·이동 시트의 시점과 화풍을 참조하되, 사용자가 요청한 단순한 선, 현대적인 머리색·장신구, 인물별 체형 차이를 반영했습니다. 목청완은 좁은 어깨·가는 팔·작은 견갑으로 아영과 구분합니다.

| 순서 | 영웅 | 배경 | 외형 |
| --- | --- | --- | --- |
| 0 | 황연청 | 도화도 문하 | 밤갈색 반묶음·옥 핀, 연두·담황, 은침 |
| 1 | 목청완 | 양가창법을 익힌 유랑 무인 | 적갈색 가는 땋은 머리·작은 견갑, 남색, 창 |
| 2 | 매설영 | 도화도 출신 사파 무인 | 흑자주 긴 머리·체인 귀걸이, 자주·먹색, 채찍 |
| 3 | 한소운 | 강남 유협 | 코퍼 브라운 포니테일·교차 핀, 백색·청색, 검 |
| 4 | 정요란 | 전진교 속가 제자 | 애쉬 실버 올림머리·기하학 비녀, 상아·회청, 검 |
| 5 | 아영 | 몽골 유목 부족 | 청록색 브레이드·금속 커프, 청록·가죽, 활 |

이름은 프로젝트의 창작 인물이며 원작의 정식 인물이라는 뜻은 아닙니다.

## 실제 규격

| 파일 | 크기 | 그리드 | 내용 |
| --- | --- | --- | --- |
| portraits.png | 1536 × 1024 | 3열 × 2행 | 위 표 순서의 초상, 셀 512 × 512 |
| run-a.png / run-b.png | 1448 × 1086 | 4열 × 3행 | 첫 3명 / 뒤 3명 이동, 셀 362 × 362 |
| cast-a.png / cast-b.png | 1448 × 1086 | 4열 × 3행 | 첫 3명 / 뒤 3명 시전, 셀 362 × 362 |
| skill-영웅ID.png 6개 | 1774 × 887 | 6열 × 3행 | 발동·진행·명중 각 6프레임 |

총 162장 분량 / PNG 11개. 초상·이동·시전은 실제 alpha 투명 이미지, 기술은 검은 배경의 screen 합성용입니다. 기술의 셀 경계는 round(index × dimension / count)로 계산합니다. 256px 또는 296px 고정 간격으로 잘라서는 안 됩니다. 원본 PNG를 코드로 리사이즈·배경 제거하지 않았습니다.

## 게임 연결

- `data/roster.ts`와 `data/heroes.ts`: 영웅 ID, 특성, 교체 기술, 초상·이동·시전 시트 지정.
- `assets/manifest.ts`: heroines 폴더 PNG 등록. `core/assets.ts`: 이동·초상·시전 프레임 로드.
- `assets/skill-art.ts`: 영웅별 6×3 기술 시트 로드. 기존 기술의 프레임 번호는 유지.
- `render/skill-animation.ts`: 시전 준비 0.16초 후 타격 자세, 총 0.32초 시전 동작. 발동 0행·진행 1행·명중 2행을 별도로 사용.
- 기본 공격은 전용 진행 원화를 작은 크기로 사용. 채찍·쾌검은 궤적의 중간 프레임을 사용하고, 교체 범위 공격에서는 진행 행을 1회 재생.
- `systems/hero-actions.ts`: 시전 지연·연속 타격을 게임 시간으로 처리. 사망·교체·새 판·관문 전환 시 남은 공격 취소.
- 6명 모두 지상 적성. 하늘 길에서는 기존 지상 영웅과 같은 비검 보조 표시를 사용하고 특성은 미발동.

일반 뽑기와 조각 성장으로 획득합니다. 신규 저장의 기본 영웅은 기존 풍운객·비천입니다. 전체 미리보기는 게임 URL/HTML에 `#debug&roster`를 붙여 실행합니다.

## 원화 갤러리

`node tools/build-heroine-gallery.mjs` → `/workspace/artifacts/heroine-art-gallery.html`.
동작/효과 개별 재생, 정지, 한 프레임 이동, 배경색 변경과 기존 풍운객 비교를 지원합니다. 실제 타격 동기화는 게임 빌드에서 확인합니다.
