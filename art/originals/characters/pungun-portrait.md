# 풍운객 슬롯의 마녀 일러스트

사용자가 제공한 정면 마녀·슬라임 설정 일러스트를 `image_gen` 편집으로 가공했다.
오른쪽 표정·SD 설정 패널, 글자, 배경 장식과 분리된 주변 장식을 제거하고
메인 캐릭터와 탑승 슬라임을 투명 배경으로 남겼다. 새 포즈를 기획한 원화가 아니라
사용자 제공 일러스트를 기반으로 한 편집본이며, 원본 픽셀을 그대로 자른 무손실 크롭은 아니다.

게임용 PNG에는 투명 여백만 잘라 6px 여유를 남겼다. 원본과 다른 캐릭터의 초상화는
공유 시트에서 덮어쓰지 않고 독립 리소스로 연결한다. `characters/pungun-portrait`를
풍운객의 portrait 키로 사용하며 영웅 목록·상세·편대·로비가 동일한 그림을 참조한다.
기존 전투 스프라이트, 표시 크기, UI 배치, 명칭과 규칙은 그대로다.
