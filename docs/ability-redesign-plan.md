# 능력 체계 개편 계획

상태: **계획.** 1단계(영웅)와 필살기 충전 방식은 정했고, 나머지는 방향만 정했다. 아직 코드는 바꾸지 않았다. 수치는 모두 임시값이며 밸런스는 나중에 한꺼번에 정한다. 용어는 [화면 용어](terms.md)를 따른다.

## 1. 왜 바꾸나

지금은 같은 일을 하는 장치가 여러 군데 흩어져 있고 서로 다른 단위로 말해서, 무엇이 더 좋은지 판단할 수 없다.

- **위력을 올리는 길이 다섯 개**: 영웅 특성, 성급, 인연 카드, 보스 강화(★★), "항상" 기술(쇄갑 등)이 따로 논다.
- **발사체를 늘리는 길이 세 개**: 교체 기술, 판 안 기술, 인연 고유 기술이 모두 비도·낙검·충격파를 쏴서 역할이 겹친다.
- **조건이 너무 많다**: 내공 충전, 지형 적성, 호감도, 계열 4개가 한 판에 얽혀 고르는 순간에 계산이 안 된다.
- **교체 효과가 제각각**이고, 하늘·땅 구분과 내공을 모아 쏘는 필살기가 의미가 약하다.

## 2. 큰 방향: 한 요소에 한 가지 일만

| 요소 | 맡는 일 | 플레이어가 묻는 질문 |
|---|---|---|
| 기술(무공) | 무엇을 쏘는가 | "뭐가 나가지?" |
| 인연 | 얼마나 세지는가 | "몇 % 올라가지?" |
| 영웅 | 특성과 등장 기술 | "누구를 선봉에, 누구를 후발에 두지?" |
| 필살기 | 위기를 넘기는 한 방 (모두 같음). 판 시작에 1개, 나머지는 특성·인연으로만 | "지금 쓸까?" |
| 보스 보상 | 기술과 인연의 짝을 진화 | "이 둘을 모으면 뭐가 되지?" |

## 3. 1단계: 영웅 (정함)

### 3.1 기본 규칙

- **편대**: 2명(선봉, 후발). 선봉이 쓰러지면 후발이 나오고, 둘 다 쓰러지면 패배. 영웅별 체력 1 규칙([영웅별 체력과 전투불능](combat-lives.md))은 그대로다.
- **수동 교체 없음**: 교체 버튼, Q키, 교체 대기, 위기·제때 교체 2배를 없앤다. 전투 HUD의 교체 버튼 자리는 비운다(다른 HUD 요소는 옮기지 않는다).
- **기본 공격**: 12명 모두 같은 성능(발수, 공격 주기, 판정, 위력, 무기 단계). 영웅마다 **발사체 그림만** 다르다.
- **지형 적성 없음**: 땅·하늘은 코스 테마(배경, 적 구성, 위험물)로만 남고, 특성은 항상 켜진다.
- **특성**: 공격력·공격 속도처럼 같은 수치를 올리는 특성은 뺀다. 자석, 치명타, 체력 +1처럼 종류가 다른 효과로 바꾼다.
  - 기본: 지금 싸우는 영웅에게만 적용
  - 지원형(운학, 황연청): 대기 중에도 편대 전체에 적용
- **등장 기술**: 후발이 등장할 때 발동한다. 적이 끝없이 내려오는 구조라 한 번 터지는 공격은 의미가 없으므로, **등장 이후 n초 동안 유지되는 효과**로 한다. 선봉에게는 없다.
- **등장 직후**: 모든 영웅 1.5초 무적. 등장 기술의 남은 시간은 캐릭터 발밑에 줄어드는 고리로 보여 준다.
- **성급**(★1~★5): 성급마다 특성 수치와 등장 기술 지속 시간이 오르고, ★3과 ★5에서 등장 기술의 모양이 바뀐다(3.3).
- **필살기**: 효과는 모두 같다. 판 시작에 1개만 있고, 처치·스침으로 내공이 차는 충전은 없앤다. 그 뒤로는 특성과 인연으로만 늘어난다(최대 3개는 임시로 유지).

### 3.2 12명

수치는 ★1 기준 임시값.

| 영웅 | 발사체 | 특성 | 적용 | 등장 기술 | 시간 |
|---|---|---|---|---|---|
| 풍운객 | 검기 | 근접 처치 시 주변 탄 제거 | 본인 | **계승**: 쓰러진 선봉의 등장 기술을 대신 펼침 | 선봉 기술의 시간 |
| 철혈 | 권기 | 체력 +1 | 본인 | **불굴**: 맞아도 쓰러지지 않고, 맞을 때마다 주변 충격파 | 15초 |
| 묵영 | 암기 | 스침 범위 +40% | 본인 | **그림자 분신**: 분신이 같은 공격을 따라 쏨 | 15초 |
| 비천 | 어검 | 기본 공격이 적 탄에 닿으면 탄을 지움 | 본인 | **어검진**: 비검 3자루가 주위를 돌며 탄을 막음 | 20초 |
| 홍련 | 비도 | 치명타 15% (피해 2배) | 본인 | **홍련화**: 모든 공격이 치명타 | 15초 |
| 목청완 | 창 | 기본 공격이 적 1명 관통 | 본인 | **관창**: 0.6초마다 정면으로 거대 관통 창 자동 투척 | 10초 |
| 매설영 | 채찍 | 처치 시 엽전 +50% | 본인 | **음풍**: 적 탄 속도 절반 | 15초 |
| 한소운 | 쾌검 | 무아지경 시간 +50% | 본인 | **질풍**: 무아지경 질주 (무적, 빠른 진행) | 8초 |
| 정요란 | 검기 | 관문마다 보호막 1회 | 본인 | **정심반사**: 맞을 뻔한 탄을 튕겨 적에게 되돌림 | 8초 |
| 아영 | 화살 | 공격 단계 +1로 시작 | 본인 | **매의 눈**: 기본 공격이 가까운 적을 자동 조준 | 12초 |
| 운학 | 깃털 | 판 시작 필살기 +1 | 편대 | **학의 장막**: 주위 결계 안에 들어온 탄이 사라짐 | 12초 |
| 황연청 | 은침 | 자석: 엽전·아이템 끌어당김 거리 2배 | 편대 | **은침 비**: 화면 위쪽 적을 은침이 자동 사격 | 20초 |

생존 계열 등장 기술은 역할을 나눴다: 철혈은 버티며 반격, 한소운은 피해 없이 질주, 운학은 주변 탄 제거, 정요란은 탄을 되돌림.

### 3.3 성급 ★3·★5 모양 변화 (제안)

성급마다 특성 수치와 지속 시간은 조금씩 오르고, ★3과 ★5에서는 아래처럼 등장 기술의 모양이 바뀐다. 영웅별 변화는 제안이며 구현 때 확정한다.

| 영웅 | ★3 | ★5 |
|---|---|---|
| 풍운객 | 계승한 기술의 시간 +50% | 선봉의 특성까지 함께 이어받음 |
| 철혈 | 충격파 범위 확대 | 불굴이 끝날 때 체력 +1 |
| 묵영 | 분신 2개 | 분신도 스침 판정을 가짐 |
| 비천 | 비검 5자루 | 비검이 가까운 적에게 날아가 공격 |
| 홍련 | 치명타 피해 2.5배 | 치명타 때 불꽃 폭발 |
| 목청완 | 창 2자루씩 | 창이 지나간 자리 폭발 |
| 매설영 | 적 이동도 느려짐 | 탄 속도 1/3 |
| 한소운 | 질주 중 닿은 적 처치 | 끝날 때 화면 탄 제거 |
| 정요란 | 되돌린 탄 위력 2배 | 모든 방향의 탄을 되돌림 |
| 아영 | 화살 관통 | 화살 2발씩 |
| 운학 | 장막 범위 확대 | 장막 안 적도 피해 |
| 황연청 | 은침 2배 | 은침이 탄도 지움 |

### 3.4 배치 전략

- **선봉**: 특성이 판 내내 일하는 영웅.
- **후발**: 등장 기술로 2막을 여는 영웅. 지원형은 대기 중에도 편대 특성이 켜져서 후발에 잘 맞는다.
- 예: 치명타 홍련 선봉 + 그림자 분신 묵영 후발.
- **풍운객 후발**: 선봉의 등장 기술은 원래 쓰일 일이 없는데, 풍운객이 후발이면 그것을 대신 펼친다. 예: 홍련 선봉 + 풍운객 후발이면 풍운객이 나올 때 홍련화(15초 모든 공격 치명타). 그래서 "선봉은 특성, 후발은 등장 기술"이라는 기본 틀 위에 "선봉의 등장 기술까지 쓰는 조합"이 하나 더 생긴다.
- 풍운객이 선봉이면 그의 등장 기술은 쓰이지 않는다(다른 선봉과 같다).

### 3.5 구현 메모 (코드 확인 결과)

지금 구조에서 모두 적용할 수 있다. 새로 만들 것은 공통 틀 세 가지와 치명타다.

- **시간형 효과 틀**: "효과 이름 + 남은 시간"을 판 상태(`RunState`)에 두고 게임 시간으로 줄인다. 무아지경(`hyper`)과 같은 방식이라 일시정지·장면 전환·새 판 초기화에 맞는다.
- **특성 적용 범위**: 지금은 `systems/formation.ts`의 `traitOn`이 "출전 중이고 지형이 맞을 때"만 켠다. 지형 조건을 빼고 "편대 전체"를 더한다.
- **수동 교체 제거**: `formation.ts`가 이미 수동(`swapHero`)과 자동(`replaceFallenHero`) 경로로 나뉘어 있다. 버튼·Q키 연결(`ui/input.ts`)과 교체 대기만 빼면 자동 등장만 남는다.
- **치명타**: 피해 계산(`hitEnemy`)에 확률 판정과 "치명" 표시를 더한다. 확률은 게임 난수(`rnd`)를 쓰고, 연출은 효과 난수(`fxRnd`)를 쓴다.

| 등장 기술 | 난이도 | 쓰는 장치 |
|---|---|---|
| 질풍 | 쉬움 | 무아지경 |
| 어검진 | 쉬움 | 회선비검의 도는 비검 |
| 은침 비 | 쉬움 | 기탄 같은 주기 자동 사격 |
| 매의 눈 | 쉬움 | 발사체 추적(`homing`)을 기본 공격에 켬 |
| 음풍 | 쉬움 | 탄 이동에 속도 배율 |
| 학의 장막 | 쉬움 | 범위 탄 제거(`clearBullets`)를 매 프레임 |
| 불굴 | 쉬움 | 피격 처리(`damagePlayer`)에서 체력 감소 대신 충격파 |
| 관창 | 쉬움 | 관통 발사체(`fireShot`의 `pierce`) + 주기 발사, 지금 회마관창 그림 재사용 |
| 정심반사 | 보통 | 태극운검의 "스친 탄을 추적탄으로 바꾸기" 응용 |
| 그림자 분신 | 보통 | 기본 공격을 옆 위치에서 한 번 더 쏨 + 분신 그리기 |
| 계승 | 쉬움 | 쓰러진 선봉 영웅의 등장 기술 함수를 대신 호출. 지속 시간과 성급 변화는 풍운객의 성급 기준(임시) |
| 홍련화 | 보통 | 치명타 시스템 |

- **비천 특성(탄 지우기)**: 기본 공격과 적 탄의 충돌 확인을 새로 더한다. 범위 탄 제거 함수가 있어 어렵지 않다(보통).
- **필살기**: 처치(+3), 보스 처치(+20), 스침(+2), 한 줄 전멸(+8)의 충전(`gainCharge`)을 뺀다. 필살기 버튼은 위치·크기 그대로 두고 횟수만 보여 준다. 충전에 기대는 요소(축기, 기탄, 만류귀종, 충전·필살기 관련 의뢰)는 2단계 이후 함께 바꾼다.

특성 중 자석(아이템 끌어당김 거리), 체력 +1(영웅별 체력), 관통·추적, 처치 시 엽전, 무아지경 시간, 관문 보호막, 공격 단계, 필살기 횟수는 해당 수치가 이미 한 곳에 있어 바로 바꿀 수 있다.

- **그림**: 학의 장막, 정심반사 검막, 그림자 분신, 발밑 고리는 처음엔 도형이나 기존 원화로 표시하고 나중에 전용 그림으로 바꾼다. 기존 영웅 6명(권기, 암기, 어검, 깃털 등)의 발사체 그림은 새로 필요하다. 여성 영웅 6명은 이미 있다.
- **검사**: 교체 버튼이 사라지므로 `tests/equivalence/combat-layout.mjs`의 기준 빌드를 새로 잡는다. 같은 시드 재현은 유지한다. 수동 교체를 쓰는 기존 E2E(시나리오 A의 Q키 교체, `mobile-ui`의 교체 버튼)는 고친다.

### 3.6 정한 것 (질문으로 확정)

- 성급: 특성 수치 + 등장 기술 지속 시간 + ★3·★5 모양 변화, 전부 적용.
- 필살기: 판 시작에 1개만. 그 뒤는 특성·인연으로만 충전.
- 운학 특성: 판 시작 필살기 +1(편대 전체).
- 비천 특성: 기본 공격이 적 탄에 닿으면 탄을 지움(아영의 자동 조준과 겹치지 않게).
- 풍운객 등장 기술: 쓰러진 선봉의 등장 기술을 대신 펼침.

## 4. 1단계 구현 범위와 수정 범위

1단계(영웅)를 코드에 옮길 때 새로 만들 것, 고칠 것, 없앨 것, 같이 바꿀 화면·테스트·문서를 파일 단위로 정리했다. 이 범위를 벗어나는 변경(인연, 기술, 진화, 밸런스)은 하지 않는다.

### 4.1 반드시 함께 들어가야 하는 묶음

- **필살기 충전 제거는 1단계와 따로 낸다.** 충전을 없애면 인연 의뢰 7개(필살기 사용 3회, 필살기로 6명 이상 처치, 충전 가득 채우기, 충전량 200)가 깰 수 없게 되고, 필살기 때 발동하는 기술(검우, 회기, 혈마해방)과 축기·기탄·만류귀종이 죽은 선택지가 된다. 그래서 필살기 변경은 2단계(인연)·3단계(기술)와 같은 묶음으로 넣는다. 1단계에서는 운학 특성(판 시작 필살기 +1)만 넣고, 충전은 그대로 둔다.
- **수동 교체 제거, 지형 적성 제거, 특성 교체, 등장 기술**은 서로 얽혀 있어(`systems/formation.ts`의 같은 함수들) 한 번에 바꾼다.

### 4.2 새로 만드는 것

| 무엇 | 위치 | 내용 |

## 5. 다음 단계 (방향만 정함)

순서대로 하나씩 정한다.

1. **인연**: 인연마다 수치 강화 하나(예: 공격력 +%, 공격 속도 +%, 스침 범위, 관문 보호막, 쓰러진 영웅 부활, 필살기 충전). 카드 단계가 오르면 그 수치가 커진다. 각 인연은 기술 하나의 진화 짝이 된다.
2. **기술**: 판 안에서 고르는 기술은 눈에 보이는 공격만 남긴다. 같은 기술을 다시 고르면 ★1 → ★3. "항상" 기술(비연보, 쇄갑, 축기, 만류귀종, 철골)은 인연 쪽으로 옮긴다. 발동 조건(좌우 전환, 스침, 근접 처치, 한 줄 전멸)은 남긴다.
3. **필살기 관련 정리**: 충전 방식은 정했다(판 시작 1개, 특성·인연으로만 충전). 충전 제거 구현은 이 단계에서 의뢰·기술 정리와 함께 넣는다(4.1). 충전에 기대는 요소(축기, 기탄, 만류귀종, 충전·필살기 관련 의뢰)와 필살기를 늘려 주는 인연 효과를 정한다.
4. **진화**: 기술 ★3과 짝 인연을 함께 가진 채 보스를 잡으면 기술이 진화한다. 기술 카드에 "짝: 비연 낭자 (있음 ✓)"처럼 적는다. 보스 기술(녹림도법, 철갑공, 천마군림)은 진화 결과물로 바꾸거나, 진화할 것이 없을 때의 보상으로 남긴다.

함께 정리할 것: 체력 1 규칙에 맞게 회복 계열(회기, 약주, 관문 통과 회복)을 보호막이나 부활로 바꾸고, 지형 적성과 호감도 수치를 정리한다.
