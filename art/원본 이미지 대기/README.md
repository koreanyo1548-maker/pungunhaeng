각 이미지의 열은 왼쪽부터 1단계, 2단계, 3단계입니다.

## 적용 전 남은 작업

- 사용자가 단계별 본체 가로폭을 조정합니다. 현재 시안의 폭은 완전히 동일하지 않습니다.
- 현재 파일은 배경·이름·구분선이 포함된 비교 시트입니다. 개별 탄 분리와 배경 제거가 필요합니다.
- 실제 적용을 승인받은 뒤, 가공한 PNG를 `art/originals/`에 등록하고 기존 변환 절차로 실행용 WebP를 만듭니다.

이 폴더는 적용 전 원본 보관용이므로 `art/originals/` 및 실행 리소스 변환 대상에 넣지 않았습니다.
전투 규칙, 판정, 발사 간격, 조작 및 기존 이미지 연결은 변경하지 않았습니다.

## 게임 적용 작업

사용자의 적용 요청에 따라 위 3장 원본을 참조한 36종 투명 원화를 `art/originals/hero-shots/`에 별도로 제작했습니다. 가로폭은 무기별 표시 비율과 단계 배율로 정리하고 `src/render/hero-shots.ts`에서 연결합니다. 이 폴더의 비교 시트 원본은 수정하지 않습니다. 자세한 좌표·변환 절차는 `art/originals/hero-shots/README.md`를 따릅니다.
