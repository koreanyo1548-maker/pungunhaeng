# 능력 체계 개편 계획

상태: **계획.** 1단계(영웅)와 2단계(스테이지·인연·보스)를 정했다. 아직 코드는 바꾸지 않았다. 수치는 모두 임시값이며 밸런스는 나중에 한꺼번에 정한다. 용어는 [화면 용어](terms.md)를 따른다.

## 1. 왜 바꾸나

지금은 같은 일을 하는 장치가 여러 군데 흩어져 있고 서로 다른 단위로 말해서, 무엇이 더 좋은지 판단할 수 없다.

- **위력을 올리는 길이 다섯 개**: 영웅 특성, 성급, 인연 카드, 보스 강화(★★), "항상" 기술(쇄갑 등)이 따로 논다.
- **발사체를 늘리는 길이 세 개**: 교체 기술, 판 안 기술, 인연 고유 기술이 모두 비도·낙검·충격파를 쏴서 역할이 겹친다.
- **조건이 너무 많다**: 내공 충전, 지형 적성, 호감도, 계열 4개가 한 판에 얽혀 고르는 순간에 계산이 안 된다.
- **교체 효과가 제각각**이고, 하늘·땅 구분과 내공을 모아 쏘는 필살기가 의미가 약하다.

## 2. 큰 방향: 한 요소에 한 가지 일만

| 요소 | 맡는 일 | 플레이어가 묻는 질문 |
|---|---|---|
| 영웅 | 특성과 등장 기술 | "누구를 선봉에, 누구를 후발에 두지?" |
| 인연 | 한 판의 빌드: 만날 때마다 1단계 수치 → 2단계 발사체 → 3단계 대표 기술 | "누구를 키우지?" |
| 선·악 저울 | 어떤 인연이 나올지 | "어느 길로 가지?" |
| 필살기 | 위기를 넘기는 한 방 (모두 같음). 판 시작에 1개, 나머지는 특성·인연으로만 | "지금 쓸까?" |
| 보스 | 스테이지의 끝. 조합 보상은 없다 | "여기까지 버틸 빌드인가?" |

처음엔 기술(무공)과 보스 보상(진화)을 따로 두려 했지만, 2단계에서 판 안 기술과 보스 기술을 모두 인연 단계로 녹이기로 해서 빌드는 인연 하나로 모인다.

## 3. 1단계: 영웅 (정함)

### 3.1 기본 규칙

- **편대**: 2명(선봉, 후발). 선봉이 쓰러지면 후발이 나오고, 둘 다 쓰러지면 패배. 영웅별 체력 1 규칙([영웅별 체력과 전투불능](combat-lives.md))은 그대로다.
- **수동 교체 없음**: 교체 버튼, Q키, 교체 대기, 위기·제때 교체 2배를 없앤다. 전투 HUD의 교체 버튼 자리는 비운다(다른 HUD 요소는 옮기지 않는다).
- **기본 공격**: 12명 모두 같은 성능(발수, 공격 주기, 판정, 위력, 무기 단계). 영웅마다 **발사체 그림만** 다르다.
- **지형 적성 없음**: 땅·하늘 구분 자체가 없어진다(5장). 특성은 항상 켜진다.
- **특성**: 공격력·공격 속도처럼 같은 수치를 올리는 특성은 뺀다. 자석, 치명타, 체력 +1처럼 종류가 다른 효과로 바꾼다.
  - 기본: 지금 싸우는 영웅에게만 적용
  - 지원형(운학, 황연청): 대기 중에도 편대 전체에 적용
- **등장 기술**: 후발이 등장할 때 발동한다. 적이 끝없이 내려오는 구조라 한 번 터지는 공격은 의미가 없으므로, **등장 이후 n초 동안 유지되는 효과**로 한다. 선봉에게는 없다.
- **등장 직후**: 모든 영웅 1.5초 무적. 등장 기술의 남은 시간은 캐릭터 발밑에 줄어드는 고리로 보여 준다.
- **성급**(★1~★5): 성급마다 특성 수치와 등장 기술 지속 시간이 오르고, ★3과 ★5에서 등장 기술의 모양이 바뀐다(3.3).
- **필살기**: 효과는 모두 같다. 판 시작에 1개만 있고, 처치·스침으로 내공이 차는 충전은 없앤다. 그 뒤로는 특성과 인연으로만 늘어난다(최대 3개는 임시로 유지).

### 3.2 12명

수치는 ★1 기준 임시값.

| 영웅 | 발사체 | 특성 | 적용 | 등장 기술 | 시간 |
|---|---|---|---|---|---|
| 풍운객 | 검기 | 근접 처치 시 주변 탄 제거 | 본인 | **계승**: 쓰러진 선봉의 등장 기술을 대신 펼침 | 선봉 기술의 시간 |
| 철혈 | 권기 | 체력 +1 | 본인 | **불굴**: 맞아도 쓰러지지 않고, 맞을 때마다 주변 충격파 | 15초 |
| 묵영 | 암기 | 스침 범위 +40% | 본인 | **그림자 분신**: 분신이 같은 공격을 따라 쏨 | 15초 |
| 비천 | 어검 | 기본 공격이 적 탄에 닿으면 탄을 지움 | 본인 | **어검진**: 비검 3자루가 주위를 돌며 탄을 막음 | 20초 |
| 홍련 | 비도 | 치명타 15% (피해 2배) | 본인 | **홍련화**: 모든 공격이 치명타 | 15초 |
| 목청완 | 창 | 기본 공격이 적 1명 관통 | 본인 | **관창**: 0.6초마다 정면으로 거대 관통 창 자동 투척 | 10초 |
| 매설영 | 채찍 | 처치 시 엽전 +50% | 본인 | **음풍**: 적 탄 속도 절반 | 15초 |
| 한소운 | 쾌검 | 무아지경 시간 +50% | 본인 | **질풍**: 무아지경 질주 (무적, 빠른 진행) | 8초 |
| 정요란 | 검기 | 판 시작 보호막 1회 | 본인 | **정심반사**: 맞을 뻔한 탄을 튕겨 적에게 되돌림 | 8초 |
| 아영 | 화살 | 공격 단계 +1로 시작 | 본인 | **매의 눈**: 기본 공격이 가까운 적을 자동 조준 | 12초 |
| 운학 | 깃털 | 판 시작 필살기 +1 | 편대 | **학의 장막**: 주위 결계 안에 들어온 탄이 사라짐 | 12초 |
| 황연청 | 은침 | 자석: 엽전·아이템 끌어당김 거리 2배 | 편대 | **은침 비**: 화면 위쪽 적을 은침이 자동 사격 | 20초 |

생존 계열 등장 기술은 역할을 나눴다: 철혈은 버티며 반격, 한소운은 피해 없이 질주, 운학은 주변 탄 제거, 정요란은 탄을 되돌림.

### 3.3 성급 ★3·★5 모양 변화 (제안)

성급마다 특성 수치와 지속 시간은 조금씩 오르고, ★3과 ★5에서는 아래처럼 등장 기술의 모양이 바뀐다. 영웅별 변화는 제안이며 구현 때 확정한다.

| 영웅 | ★3 | ★5 |
|---|---|---|
| 풍운객 | 계승한 기술의 시간 +50% | 선봉의 특성까지 함께 이어받음 |
| 철혈 | 충격파 범위 확대 | 불굴이 끝날 때 체력 +1 |
| 묵영 | 분신 2개 | 분신도 스침 판정을 가짐 |
| 비천 | 비검 5자루 | 비검이 가까운 적에게 날아가 공격 |
| 홍련 | 치명타 피해 2.5배 | 치명타 때 불꽃 폭발 |
| 목청완 | 창 2자루씩 | 창이 지나간 자리 폭발 |
| 매설영 | 적 이동도 느려짐 | 탄 속도 1/3 |
| 한소운 | 질주 중 닿은 적 처치 | 끝날 때 화면 탄 제거 |
| 정요란 | 되돌린 탄 위력 2배 | 모든 방향의 탄을 되돌림 |
| 아영 | 화살 관통 | 화살 2발씩 |
| 운학 | 장막 범위 확대 | 장막 안 적도 피해 |
| 황연청 | 은침 2배 | 은침이 탄도 지움 |

### 3.4 배치 전략

- **선봉**: 특성이 판 내내 일하는 영웅.
- **후발**: 등장 기술로 2막을 여는 영웅. 지원형은 대기 중에도 편대 특성이 켜져서 후발에 잘 맞는다.
- 예: 치명타 홍련 선봉 + 그림자 분신 묵영 후발.
- **풍운객 후발**: 선봉의 등장 기술은 원래 쓰일 일이 없는데, 풍운객이 후발이면 그것을 대신 펼친다. 예: 홍련 선봉 + 풍운객 후발이면 풍운객이 나올 때 홍련화(15초 모든 공격 치명타). 그래서 "선봉은 특성, 후발은 등장 기술"이라는 기본 틀 위에 "선봉의 등장 기술까지 쓰는 조합"이 하나 더 생긴다.
- 풍운객이 선봉이면 그의 등장 기술은 쓰이지 않는다(다른 선봉과 같다).

### 3.5 구현 메모 (코드 확인 결과)

지금 구조에서 모두 적용할 수 있다. 새로 만들 것은 공통 틀 세 가지와 치명타다.

- **시간형 효과 틀**: "효과 이름 + 남은 시간"을 판 상태(`RunState`)에 두고 게임 시간으로 줄인다. 무아지경(`hyper`)과 같은 방식이라 일시정지·장면 전환·새 판 초기화에 맞는다.
- **특성 적용 범위**: 지금은 `systems/formation.ts`의 `traitOn`이 "출전 중이고 지형이 맞을 때"만 켠다. 지형 조건을 빼고 "편대 전체"를 더한다.
- **수동 교체 제거**: `formation.ts`가 이미 수동(`swapHero`)과 자동(`replaceFallenHero`) 경로로 나뉘어 있다. 버튼·Q키 연결(`ui/input.ts`)과 교체 대기만 빼면 자동 등장만 남는다.
- **치명타**: 피해 계산(`hitEnemy`)에 확률 판정과 "치명" 표시를 더한다. 확률은 게임 난수(`rnd`)를 쓰고, 연출은 효과 난수(`fxRnd`)를 쓴다.

| 등장 기술 | 난이도 | 쓰는 장치 |
|---|---|---|
| 질풍 | 쉬움 | 무아지경 |
| 어검진 | 쉬움 | 회선비검의 도는 비검 |
| 은침 비 | 쉬움 | 기탄 같은 주기 자동 사격 |
| 매의 눈 | 쉬움 | 발사체 추적(`homing`)을 기본 공격에 켬 |
| 음풍 | 쉬움 | 탄 이동에 속도 배율 |
| 학의 장막 | 쉬움 | 범위 탄 제거(`clearBullets`)를 매 프레임 |
| 불굴 | 쉬움 | 피격 처리(`damagePlayer`)에서 체력 감소 대신 충격파 |
| 관창 | 쉬움 | 관통 발사체(`fireShot`의 `pierce`) + 주기 발사, 지금 회마관창 그림 재사용 |
| 정심반사 | 보통 | 태극운검의 "스친 탄을 추적탄으로 바꾸기" 응용 |
| 그림자 분신 | 보통 | 기본 공격을 옆 위치에서 한 번 더 쏨 + 분신 그리기 |
| 계승 | 쉬움 | 쓰러진 선봉 영웅의 등장 기술 함수를 대신 호출. 지속 시간과 성급 변화는 풍운객의 성급 기준(임시) |
| 홍련화 | 보통 | 치명타 시스템 |

- **비천 특성(탄 지우기)**: 기본 공격과 적 탄의 충돌 확인을 새로 더한다. 범위 탄 제거 함수가 있어 어렵지 않다(보통).
- **필살기**: 처치(+3), 보스 처치(+20), 스침(+2), 한 줄 전멸(+8)의 충전(`gainCharge`)을 뺀다. 필살기 버튼은 위치·크기 그대로 두고 횟수만 보여 준다. 충전에 기대는 요소(축기, 기탄, 만류귀종, 충전·필살기 관련 의뢰)는 2단계 이후 함께 바꾼다.

특성 중 자석(아이템 끌어당김 거리), 체력 +1(영웅별 체력), 관통·추적, 처치 시 엽전, 무아지경 시간, 판 시작 보호막, 공격 단계, 필살기 횟수는 해당 수치가 이미 한 곳에 있어 바로 바꿀 수 있다.

- **그림**: 학의 장막, 정심반사 검막, 그림자 분신, 발밑 고리는 처음엔 도형이나 기존 원화로 표시하고 나중에 전용 그림으로 바꾼다. 기존 영웅 6명(권기, 암기, 어검, 깃털 등)의 발사체 그림은 새로 필요하다. 여성 영웅 6명은 이미 있다.
- **검사**: 교체 버튼이 사라지므로 `tests/equivalence/combat-layout.mjs`의 기준 빌드를 새로 잡는다. 같은 시드 재현은 유지한다. 수동 교체를 쓰는 기존 E2E(시나리오 A의 Q키 교체, `mobile-ui`의 교체 버튼)는 고친다.

### 3.6 정한 것 (질문으로 확정)

- 성급: 특성 수치 + 등장 기술 지속 시간 + ★3·★5 모양 변화, 전부 적용.
- 필살기: 판 시작에 1개만. 그 뒤는 특성·인연으로만 충전.
- 운학 특성: 판 시작 필살기 +1(편대 전체).
- 비천 특성: 기본 공격이 적 탄에 닿으면 탄을 지움(아영의 자동 조준과 겹치지 않게).
- 정요란 특성: 관문이 없어져서 '판 시작 보호막 1회'로 바꿈(2단계에서 결정).
- 풍운객 등장 기술: 쓰러진 선봉의 등장 기술을 대신 펼침.

## 4. 1단계 구현 범위와 수정 범위

1단계(영웅)를 코드에 옮길 때 새로 만들 것, 고칠 것, 없앨 것, 같이 바꿀 화면·테스트·문서를 파일 단위로 정리했다. 이 범위를 벗어나는 변경(인연, 기술, 진화, 밸런스)은 하지 않는다.

### 4.1 반드시 함께 들어가야 하는 묶음

- **필살기 충전 제거는 1단계와 따로 낸다.** 충전을 없애면 인연 의뢰 7개(필살기 사용 3회, 필살기로 6명 이상 처치, 충전 가득 채우기, 충전량 200)가 깰 수 없게 되고, 필살기 때 발동하는 기술(검우, 회기, 혈마해방)과 축기·기탄·만류귀종이 죽은 선택지가 된다. 그래서 필살기 변경은 2단계(스테이지·인연·보스, 5장)와 같은 묶음으로 넣는다. 1단계에서는 운학 특성(판 시작 필살기 +1)만 넣고, 충전은 그대로 둔다.
- **수동 교체 제거, 지형 적성 제거, 특성 교체, 등장 기술**은 서로 얽혀 있어(`systems/formation.ts`의 같은 함수들) 한 번에 바꾼다.

## 5. 2단계: 스테이지·인연·보스 (정함)

### 5.1 스테이지

- **한 판 = 보스 한 명의 스테이지.** 관문 1·2·3과 최종 관문이 없어지고, 한 배경에서 보스가 나올 때까지 길게 이어진다.
- **땅·하늘 구분 없음.** 하늘 배경도 쓰지만 이동은 지금 땅의 규칙(좌우 이동)만 남긴다. 하늘의 상하 자유 이동은 코드에 숨겨 두고 쓰지 않는다.
- **6개 스테이지를 순서대로 연다.** 앞 스테이지에서 보스를 잡으면 다음이 열린다.

| 스테이지 | 배경 | 보스 |
|---|---|---|
| 1 | 산길 | 녹림 채주 |
| 2 | 청죽림 | 철갑 권승 |
| 3 | 폐사 | 천마 교주 |
| 4 | 부유암 | 녹림 채주 |
| 5 | 유운봉 | 철갑 권승 |
| 6 | 천마성 | 천마 교주 |

- **보스 등장**: 정해진 거리를 달리면 나온다. 보스를 잡으면 스테이지 완료(보상 화면 없음).
- **심마**: 스테이지에서 빼고, 나중에 특별 스테이지로 만든다.

### 5.2 처치 게이지와 만남

- 적을 처치하면 게이지가 차고, 가득 차면 만남이 열린다. 보스까지의 거리 안에서 약 6번 차도록 맞춘다.
- 만남: 나올 수 있는 인연이 있으면 **인연 한 명이 의뢰를 들고** 오고, 없으면 **행인**이 온다.
- 나올 수 있는 인연 = 인연 카드가 있고(뽑기), 선·악 저울로 해금된 인연.

### 5.3 선·악 저울

- 하나의 저울. 선 쪽 행동은 +, 악 쪽 행동은 −.
- 행인에게 하는 행동과 인연 의뢰를 따르거나 거스르는 선택이 모두 저울을 움직인다.
- **해금**: 저울이 선·악 각각 1·3·5에 닿을 때마다 그쪽 인연이 한 명씩 열린다. 한 번 열린 인연은 저울이 다시 내려가도 그 판 동안 유지된다.

| 저울 | 정파 (선) | 사파 (악) |
|---|---|---|
| 1 | 떠돌이 약선 | 비연 낭자 |
| 3 | 청운 도인 | 녹림 의적 |
| 5 | 철벽 노승 | 혈마 밀사 |

- 판 시작(0)에는 열린 인연이 없어서 첫 만남은 행인이다. 여기서 고른 방향으로 길이 열린다.
- 엽전 보너스(덕 1당 보관 엽전 +1%)는 없앤다.

### 5.4 행인

- 의뢰가 없는 일반 NPC. 한 판에서 만날수록 단계가 오른다(2단계까지).
- **1단계** (첫 만남): 돕는다(선 +1) / 무시한다(악 +1)
- **2단계** (두 번째부터): 엽전을 베푼다(선 +2, 엽전 사용) / 안 베푼다(악 +1). 엽전을 빼앗는 선택지는 없다. 저울 수치는 임시.

### 5.5 인연 의뢰

- 인연은 한 명이 와서 의뢰를 준다. 의뢰는 다음 게이지가 차기 전까지 이뤄야 한다.
- **따른다**: 그 인연 쪽으로 저울이 움직인다(정파 선 +1, 사파 악 +1). 성공하면 그 인연이 한 단계 오른다. 3단계를 다 채운 뒤에는 엽전.
- **거스른다**: 반대쪽으로 저울이 움직인다. 성공하면 단계 대신 엽전.
- **실패**: 저울은 고른 대로 움직이고, 보상만 없다.
- 필살기 사용·충전을 조건으로 하는 의뢰 7개는 스침, 좌우 전환, 근접 처치, 한 줄 전멸, 연속 처치로 바꾼다.
- 호감도, 맞수 +1, 다음 인연 고리(`NPC_LINK`), 고유 기술 전수, 최종 관문의 도움·방해는 없어진다.

### 5.6 인연 빌드업 (정함)

만날 때마다 1단계 수치 → 2단계 발사체 기술 → 3단계 대표 기술. 굵은 글씨는 보스 기술을 옮긴 것. 수치는 임시값.

| 인연 | 진영 | 1단계 (수치) | 2단계 (발사체) | 3단계 (대표 기술) |
|---|---|---|---|---|
| 떠돌이 약선 | 정파 | 체력 +1 | 기탄: 추적 약환 자동 발사 | 회춘단: 일정 시간마다 피격 1회 무효 |
| 청운 도인 | 정파 | 스침 범위 +25% | 유수파: 스칠 때 파동 | 태극운검: 스친 탄을 추적탄으로 되돌림 |
| 철벽 노승 | 정파 | 장갑 적·보스 피해 +40% | 붕산권: 근접 처치 시 충격파 | **철갑공**: 10초마다 보호막 |
| 비연 낭자 | 사파 | 공격 속도 +12% | 잔영검: 좌우 전환 시 검기 2발 | 만천화우: 좌우 전환 시 비도 부채 |
| 녹림 의적 | 사파 | 공격력 +15% | 의협난도: 한 줄 전멸 시 5방향 관통 | **녹림도법**: 1.4초마다 7방향 도기 |
| 혈마 밀사 | 사파 | 필살기 +1 (최대 +1) | 검우: 필살기를 쓰면 검의 비 | **천마군림**: 3초마다 가장 강한 적에게 검강 |

- **인연 카드**(뽑기): 카드가 있어야 나오고, 카드 단계(1~5)가 오르면 그 인연의 1·2·3단계 수치가 커진다. 지금의 "전수 완화", "최종 관문 도움 강화"는 없어진다.
- **필살기를 늘리는 길**: 판 시작 1개 + 운학 특성(판 시작 +1) + 혈마 밀사 1단계.
- **판 안 기술 선택은 없어진다.** 위 표에 쓰이지 않는 기존 기술(무영신법, 회선비검, 연환격, 철골, 축기, 회기, 비연보, 혈마해방, 금강부동, 파진검강)은 빼거나, 영웅 등장 기술의 재료로 쓴다(어검진은 회선비검 방식).

### 5.7 없어지는 것

- 관문 구조(관문 1·2·3, 최종 관문, 관문 통과 회복), 코스 선택(땅의 길·하늘의 길)
- 객잔(약주, 필살 단약, 명상, 수소문)
- 보스 기술 화면(★★ 조합, 새로 배우기, 엽전 250냥)
- 기술 선택 화면(의뢰 성공 후)과 계열(회피·공격·필살·보스) 기반 보상, 지형별 수월한 계열
- 호감도, 맞수, 다음 인연 고리, 고유 기술 전수, 최종 관문 도움·방해
- 덕과 엽전 보너스(선·악 저울로 대체)
- 필살기 충전(처치·스침·한 줄 전멸·보스 처치) — 1단계에서 미뤄 둔 것을 여기서 넣는다

### 5.8 정한 것 (질문으로 확정)

- 보스 기술 조합 제거, 보스 기술은 인연 3단계로 배분
- 보스는 스테이지마다 1명, 배경은 그 보스의 지역 하나, 심마는 나중에 특별 스테이지
- 관문 대신 처치 게이지로 만남, 한 판 약 6번
- 선·악은 하나의 저울, 행인 행동과 인연 선택 모두로 움직임, 단계별(1·3·5) 한 명씩 해금
- 인연은 한 명이 와서 의뢰, 따름/거스름은 인연 진영에 따라 저울 이동, 실패는 보상만 없음
- 판 안 기술은 인연 단계로 녹임, 객잔 없앰
- 인연 카드 = 등장 자격 + 효과 강화
- 행인은 만날수록 단계 상승(2단계까지), 1단계 돕는다/무시한다, 2단계 엽전을 베푼다/안 베푼다
- 스테이지 6개(땅 배경 3, 하늘 배경 3), 이동은 좌우만, 하늘 스테이지도 땅과 같은 보스 순서
- 엽전 보너스 없앰, 보스는 거리 뒤 등장, 인연 빌드업 표 확정, 정요란 판 시작 보호막

### 5.9 아직 정하지 않은 것 (밸런스 때 정함)

- 게이지 크기, 보스까지의 거리, 스테이지별 적 강도
- 행인 2단계에서 베푸는 엽전 액수, 거스름 성공·3단계 이후 만남의 엽전 액수
- 인연 단계별 수치, 카드 단계별 증가폭
- 바뀐 의뢰 7개의 구체 조건과 목표치

## 6. 2단계 구현 범위와 수정 범위

1단계(영웅)와 함께 넣을지, 따로 넣을지는 구현 순서를 정할 때 고른다. 2단계는 판 흐름 자체가 바뀌어서 기존 E2E 대부분을 다시 써야 한다.

### 6.1 새로 만드는 것

| 무엇 | 위치 | 내용 |
|---|---|---|
| 스테이지 정의 | `data/courses.ts` → 스테이지 6개 | 배경(지역), 보스, 거리, 이동 규칙(모두 좌우) |
| 스테이지 진행 저장 | `core/profile.ts`, `data/meta.ts` | 연 스테이지 수. 저장 형식에 항목 추가(빠진 저장은 1스테이지만 열림으로 채움) |
| 스테이지 선택 화면 | `scenes/setup.ts`(코스 선택 자리) | 잠긴 스테이지 표시 |
| 처치 게이지 | `systems/stage-phases.ts` 또는 새 `systems/encounter.ts` | 처치로 차고, 가득 차면 만남 장면 |
| 선·악 저울과 해금 | 새 `systems/alignment.ts` | 저울 값, 1·3·5 해금, 판 동안 유지 |
| 행인 단계 | `systems/virtue.ts` → 행인 행동 | 1단계 돕는다/무시한다, 2단계 엽전을 베푼다/안 베푼다 |
| 인연 단계 빌드 | `data/npcs.ts`, `systems/abilities.ts` | 인연별 1·2·3단계 효과와 판 안 단계 상태 |
| 게이지·거리 표시 | `ui/hud.ts`, `index.html`의 관문 표시(`#stageHud`) | 지금 관문 표시 상자 안에 글자와 막대로 넣는다. 위치·크기는 그대로 |

### 6.2 고치는 것

| 파일 | 고칠 내용 |
|---|---|
| `systems/run-plan.ts`, `systems/scene-flow.ts` | 관문 계획 → 스테이지 하나. 장면 순서: 편성 → 비행 ↔ 만남(인연·행인) → 보스 → 결과 |
| `systems/stage-phases.ts`, `systems/flow.ts` | 관문 단계와 시간 기준 길이 → 거리 기준, 관문 통과 처리(회복, 필살기 +1) 제거, `movementTier`를 좌우 이동으로 고정 |

| `systems/relationship.ts` | 다음 인연 고리 → 저울 해금과 카드로 고르기 |

| `data/skills.ts`, `systems/abilities.ts`, `systems/skill-state.ts` | 기술 정의를 인연 단계 효과로 재배치, 보스 기술 조합(`mod`, `ARTS`) 제거 |
| `data/branches.ts` | 계열과 의뢰 조건. 계열 보상 제거, 필살기 조건 제거 |

| `scenes/cards.ts`, `scenes/gacha.ts` | 인연 카드 설명(전수·최종 관문 도움 → 단계 수치 강화) |

### 6.3 없애는 파일

- `scenes/dono.ts`(기술 선택), `scenes/tuhak.ts`(보스 기술), `scenes/inn.ts`(객잔)
- `scenes/final-gate.ts`(최종 관문)는 심마 특별 스테이지 때 다시 볼 수 있게 남겨 두되 흐름에서 뺀다

### 6.4 바꾸지 않는 것

- 전투 HUD 배치(관문 표시 상자 안의 내용만 바뀜), 기본 공격, 적·탄·보스 패턴, 영웅별 체력
- 저장의 영웅 조각·인연 조각, 뽑기
- 게임 난수와 효과 난수 분리, 같은 시드 재현
