# 판 밸런스 기준 (드래곤플라이트 기준)

> 아래 표와 봇 측정은 #34의 1차 적용을 기록한다. 이후 적용한 S1 하강 300 → 600px/s, 등급별 체력 간격 축소, 무아지경 지속 시간, 아이템 드롭(처치당 통합 1%, 무아지경 4 : 자석 4 : 점수 두 배 2)은 [현재 전투 수치](combat-stats.md)를 따른다.
>
> 아래의 봇 측정은 실제 플레이 체감과 크게 달라 앞으로 조정 근거로 쓰지 않는다. 밸런스는 사용자의 직접 플레이로 맞춘다([작업 규칙](workflow.md) 8장).

모든 스테이지에 공통으로 쓰는 판의 뼈대다. 기준은 드래곤플라이트(이하 DF) 초반 플레이 영상이고, 2026-11 이전의 우리 수치는 임시값이라 기준으로 삼지 않는다. 우리 게임의 핵심인 **메타 성장**(영웅 레벨·성급·호감도)과 **판 안 스킬 다양화**(인연 기술·특성·등장 기술)가 차이를 만들 자리를 남기는 것이 DF와 다른 점이다.

- 그림·연출 쪽 요청은 [Codex 전달: 판 기준 개편에 필요한 아트](codex-art-handoff.md)에 따로 적었다.
- 지금 코드의 수치(공격력, 체력 순서)는 [공격력과 체력](combat-stats.md)에 있다. 이 문서대로 바꾸면서 그 문서도 고친다.

## 1. DF 측정값

자료: "Dragon Flight for Kakao - iPhone & iPad Gameplay Video"를 화면 녹화한 62초 영상. 실제 플레이는 11~59초(48초, 1,710m)다. 게임 화면만 잘라 24fps로 뽑고, 위쪽 거리·점수·엽전 숫자, 적 줄의 움직임, 체력바의 줄어드는 속도를 쟀다. 녹화 영상이 프레임을 빼먹거나 겹치는 곳이 있어 시간 수치는 ±0.1초쯤 오차가 있다.

|---|---|

## 2. 공통 뼈대 (모든 스테이지)

| 항목 | 기준 |
|---|---|
| 판 길이 | 보스까지 약 3분. 등급 6단계(약 30초씩). 만남 횟수는 나중에 조정 |
| 속도 | 적 하강과 진행 속도가 3분에 걸쳐 2배가 된다. 시작은 DF 초반(줄이 화면 80%까지 1.2초) |
| 줄 간격 | DF 기준 1.7초 → 1.45초 |
| 한 줄 | 5칸 |
| 등급 사다리 | 스테이지마다 1등급부터 다시 시작한다. 단계 k에서 약한 칸은 k등급이고, 나머지 칸은 k·k+1·k+2 등급이 섞이며 뒤로 갈수록 높은 등급이 늘어난다. 단계가 오르면 아래 등급은 사라지고 다음 등급이 약한 칸이 된다(흰 용이 영원히 남지 않는다) |
| 등급 체력 | 기준 성장치의 기본 공격으로 1·10·18·32·58·105발. 2등급은 1등급의 10배, 3등급부터 앞 등급의 1.8배(DF 측정) |
| 거리 배율 | 없다. 판 안 체력 증가는 등급 사다리로만 |
| 보스 | 기준 성장치의 기본 공격만으로 약 30초 |
| 기본 공격 | 초당 약 16발, 탄 속도 1초에 화면 약 2.2배 |
| 운석 | 평균 약 30초마다 확률적으로, 경고 2초, 플레이어 위치를 노림 |
| 무아지경(질주) | 약 1.4초, 진행 약 6배 속도, 앞의 적을 모두 부숨, 끝에 화면 전체 폭발로 남은 적이 엽전으로 바뀜. 처치당 확률로 3분 판 평균 6번(판마다 들쭉날쭉). 무아지경 처치는 아이템을 떨어뜨리지 않음 |
| 자석·점수 두 배 | 처치 드롭, 처치당 확률로 3분 판 평균 각 2번 |
| 보물상자 | 줄의 한 칸에 확률로 섞임(3분 판 평균 2번, 줄당 약 1.8%). 체력은 그 단계의 강한 적(k+1)과 같음. 터지면 보석 약 10개가 사방으로 튀어 떨어짐 |
| 보석 | 먹으면 엽전 5개(점수도 엽전 5개 몫). 따로 쌓는 재화가 아님 |
| 엽전 | 처치하면 튀었다 떨어짐, 끌어오지 않음(황연청·자석 아이템만 끌어옴). 연속 획득 배수 없음 |
| 아이템 움직임 | 엽전과 같이 튀었다 떨어지되, 꼭대기에서 0.4~0.5초 머문다 |
| 달성 보너스 | 기준 점수(기준 성장치 평균 점수, 무적 봇 측정)의 100·150·200%에 판 끝 엽전 +10·20·30% |
| 만남 | 의뢰를 이루면 다음 만남(첫 만남 비행 10초 뒤, 의뢰 제한 60초, 행인 뒤 10초). 처치 게이지는 없앴다(2026-11 2차, [기술 개편 계획](ability-redesign-plan.md) 4.2) |
| 지형 규칙 | S1에는 없다. S2부터 하나씩 더한다(바위, 죽창, 운해의 느린 줄) |

## 3. 성장과 스킬을 위한 원칙

- **체력은 "기준 성장치에서 걸리는 처치 시간"으로 정한다.** S1의 기준 성장치는 영웅 Lv1·인연 없음이다. S2부터는 스테이지마다 권장 성장치를 정한다. 레벨을 올리면 처치 시간이 짧아지는 것이 성장의 손맛이다.
- **3단계부터는 기본 공격만으로 약한 칸을 제때 못 뚫는다.** 줄이 지나가는 시간은 후반에 약 0.8초인데, Lv1 기본 공격으로 3단계 약한 칸(18발)은 약 1.1초, 4단계(32발)는 약 2초 걸린다. 판 안 인연 기술과 메타 성장이 이 줄을 뚫어 주는 역할이다. 스킬의 차이가 판에서 보이게 하려는 의도다.
- **확률 이벤트는 고정 시각이 아니라 처치나 줄마다 굴리는 확률로 둔다.** 평균 횟수만 맞추고 판마다 들쭉날쭉하게 한다(무아지경, 자석, 점수 두 배, 보물상자, 운석).

## 4. S1 적용 (적용됨)

화면은 480×800, 플레이어 y 654. 줄은 y −70에서 나온다.

| 항목 | S1 값 |
|---|---|
| 적 하강 속도 | 줄이 화면 80%(y 640)까지 시작 1.2초, 3분 뒤 0.6초. 약 590px/초 → 약 1,180px/초 |
| 진행 속도 | 같은 비율로 2배 |
| 줄 간격 | 1.7초 → 1.45초. 3분에 약 115줄 |
| 등급 체력(Lv1 공격력 10 기준) | 10 · 100 · 180 · 320 · 580 · 1,050 |
| 단계 안 구성 | 처음 값: 약한 칸 k등급 1칸. 나머지 4칸 중 k+1 비율이 단계 안에서 20% → 60%, k+2가 0% → 20%. 6등급 위는 6등급으로 자름 |
| 보스 체력 | 30초 × Lv1 초당 피해 |
| 기본 공격 | Lv1 두 발 묶음을 0.125초마다(초당 16발). 탄 속도 약 1,760px/초 |
| 처치당 확률 | 무아지경 6%, 자석 2%, 점수 두 배 2% (무아지경 처치는 굴리지 않음). 보물상자는 줄마다 1.8% |
| 스테이지 길이 | 무아지경 없이 185초를 달리는 거리(S1 22,700m) |
| 없앤 것 | 거리 배율, S1 바위, 6초마다의 운석, 4.2초 무아지경, 기존 강한 적 비율(`earlyWeak` 등) |

측정(봇, `tests/sim/balance.mjs`; 봇은 줄이 가까워지면 뚫린 칸에서 기다린다):

| | 무적 봇 12판 평균 | 일반 봇(Lv1·인연 없음) 8판 |
|---|---|---|
| 보스까지 | 182초(보스전 34초) | 평균 약 90초에 쓰러짐(3~4단계) |
| 처치 | 125 | 137 |
| 무아지경 · 자석 · 점수 두 배 · 보물상자 | 5.3 · 1.8 · 2.3 · 1.8번 | — |
| 만남 | 6.5번(게이지 36, 10판) | 4.8번(쓰러지기 전, 6판) |

- 기준 성장치에서 3~4단계에 막히는 것은 설계대로다(인연 기술·성장이 뚫어 줄 자리).
- 만남 게이지는 처치 수 대신 등급만큼 채우고, 크기를 S1 36으로 줄였다(이전 90). S2~S6 크기(20·37·34·30·44)는 무적 봇 3판 측정이라 임시다.
