# 기술 이미지 애니메이션 제작 기록

기준: main `7ea038e` (pixelfx 및 화면 용어 정리 포함). 전투 배치·판정·공격 주기·스킬 규칙은 유지한다.

## 이번 1차 적용

24개 습득 기술에 대응하는 6프레임 효과 144장, 6종 발사체 비행 반복 프레임 36장, 6명 교체 자세 24장. 총 8개 시트, 204개 프레임이다. 원화는 이미지 생성 도구로 제작했다. 캐릭터 시트는 알파 투명 PNG이고, 효과 시트는 검은 바탕의 빛 합성용 원화로 `screen` 합성한다. 런타임에서 도형으로 기술 형상을 대신 그리지 않는다.

하나의 효과 행은 생성·전개·완성·방출·파열·소멸 6단계다. 발동에는 전체 순서를, 즉시 타격에는 후반 3프레임을 사용한다. 유지 상태에는 중간 프레임을 사용한다. 기술마다 별도의 발동/명중 시트를 각각 6–8장 제작한 최종판은 아니며, 이번 결과를 실제 전투 크기에서 검토한 후 필요한 구간을 추가 제작한다.

| 시트 | 행 순서 | 실제 연결 |
|---|---|---|
| signature | 만천화우, 유수파, 철갑공, 천마군림 | 발사·범위 타격·보호막 상태·낙검 |
| movement | 잔영검, 비연보, 무영신법, 회선비검 | 잔영 발사·스침·무적 유지·검 생성/회전/접촉 |
| attack | 붕산권, 파진검강, 연환격, 의협난도 | 근접 처치 파동·관통탄 발사/명중 |
| passive | 철골, 쇄갑, 축기, 만류귀종 | 습득·추가 피해 대상·실제 충전·습득 |
| energy | 검우, 기탄, 회기, 태극운검 | 낙검·추적탄·실제 회복·되쏘기 |
| secret | 혈마해방, 금강부동, 회춘단, 녹림도법 | 발동/유지·범위타격/방어·준비/소진·도기 |
| flight | 꽃잎 비도, 쌍검기, 관통 검강, 도기, 기탄, 태극탄 | 안정된 탄 중심과 6프레임 반복 비행 |
| swap-poses | 풍운객, 철혈, 묵영, 비천, 운학, 홍련 | 교체 직후 방출·후속 동작·회수·복귀 4프레임 |

모든 파일은 `src/assets/images/skills/`에 있다. 교체 기술의 이펙트는 계열에 맞는 위 효과를 재사용하고, 인물 동작은 별도 제작한 자세로 교체한다. 강화 교체는 기존 규칙의 탄수·폭·위력을 따르며 발동 효과 크기를 구분한다. 기본 공격 원화와 기존 공용 필살기 연출을 점검 후 유지하고, 공용 필살기에 기운 수렴 이미지 시퀀스를 추가했다.

## 발동과 판정의 연결

- 동기식 스킬 문맥을 `withSkill`로 보관하고, 발사체에 순수 시각 메타데이터 `skill`을 붙인다. 연쇄 처치로 다른 스킬이 발동해도 `try/finally`로 원래 문맥으로 복귀한다.
- 피해·탄속·궤적·쿨다운·게임 RNG를 변경하지 않는다. 발동 연출 때문에 피해를 지연시키지 않는다.
- 회기는 체력이 실제 증가한 경우에만 성공 연출을 표시한다. 대상 없는 천마군림에는 성공 연출이 없다.
- 철갑공/회춘단은 실제 보호 상태 변화를 읽는다. 소진 시 남은 생성 프레임을 지우고 파열로 전환한다.
- 습득 순간 표시하기 어려운 상시 효과는 다음 실제 전투 진입에 습득 연출을 표시한다.
- 일시정지 동안 시각 시간도 멈춘다. 재시작·사망·관문 전환에 효과를 정리한다. 캐릭터 전용 유지 효과는 교체 시 해제하고 공용 보호 상태는 실제 게임 상태를 따른다.
- 효과는 최대 48개, 동일 기술은 최대 5개로 제한한다. 고빈도 명중의 겹치는 잔광만 제한하고 실제 공격 발동에는 영향을 주지 않는다.
- 동작 줄이기에서는 대표 프레임을 낮은 밝기로 표시하고 교체 자세 애니메이션을 생략한다.
- pixelfx는 일반 타격/폭발 등 공용 보조 효과로 유지한다. 전용 기술 명중에는 새 원화를 우선한다.

## 검토 산출물과 검사

- `node tools/build-skill-gallery.mjs`: 원화 8시트를 포함한 오프라인 검토 HTML. 재생/정지, 프레임 선택, 배경 밝기, 재생 속도 조절. 파일 기본 경로 `/workspace/artifacts/skill-animation-gallery.html`.
- `node tests/e2e/skill-art.mjs`: Vite를 직접 실행하여 일반/동작 줄이기에서 24개 기술, 3개 조합, 6명 교체를 검사한다. 무효 발동·보호막 소진·문맥 복귀·재시작을 확인한다. `SCREENSHOT_DIR`로 캡처 경로 지정 가능.
- `npm test`, `npm run test:ui`, 일반 빌드, 이전 HTML과 동일 입력 비교를 수행한다.
- 기술별 정지 화면과 실제 전투 재생 영상은 첫 검토 자료다. 게임 상태가 같다는 자동 검사가 연출의 미적 완성도를 보장하지는 않는다.

## 후속 검토 항목

각 기술에서 실제 크기의 식별력, 반복 루프의 이음새, 피격/격파 중첩, 탄막 가림을 비교한다. 특히 교체 자세와 달리기/비행 자세의 몸 크기 연결, 혈마해방과 적탄의 붉은색 구분, 고빈도 유수파·붕산권의 중첩 밝기를 중점 검토한다. 검토 후 필요한 기술에 추가 프레임을 제작하며, 공통 연출을 무조건 크게 만드는 방식으로 보완하지 않는다.
