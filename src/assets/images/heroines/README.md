# 여성 영웅 6명 · 원화 리소스

기존 `portraits.png`, `hero-run.png`, `skills/swap-poses.png`, `skills/attack.png`를 직접 참조해 그린 신규 원화입니다. 먹선, 피부 음영, 직물 질감과 뒷모습 카메라를 맞추고 머리·겹옷·장식으로 인물을 구분했습니다. 기존 영웅 원화는 교체하지 않았습니다.

현재는 **원화 검수 단계**입니다. 영웅 데이터 등록, 스킬 규칙, 로더 연결과 실제 전투 타이밍은 포함하지 않습니다. 이름은 기획용 가칭이며 김용 작품의 정식 등장인물이라는 뜻은 아닙니다.

| 순서 | 가칭 | 소속 / 배경 | 시각적 특징 |
| --- | --- | --- | --- |
| 0 | 황연청 | 도화도 문하 | 연두·담황, 반묶음, 옥 장식, 은침 |
| 1 | 목청완 | 양가창법을 익힌 유랑 무인 | 남색·적색, 굵은 땋은 머리, 가죽 견갑, 붉은 수술 창 |
| 2 | 매설영 | 도화도 출신 사파 무인 | 먹색·자주, 긴 흑발, 채찍과 조갑 |
| 3 | 한소운 | 강남 유협 | 백색·청색, 높은 포니테일, 경쾌한 검격 |
| 4 | 정요란 | 전진교 속가 제자 | 회청·상아, 올림머리, 절제된 직선 검기 |
| 5 | 아영 | 몽골 유목 부족 | 청록·가죽, 여러 갈래 땋은 머리, 작은 털깃, 복합궁 |

## 구성과 실제 파일 규격

| 파일 | 실제 크기 | 그리드 | 내용 |
| --- | --- | --- | --- |
| `portraits.png` | 1536 × 1024 | 3열 × 2행 | 위 표 순서대로 초상 6장, 각 512 × 512 |
| `run-a.png` | 1448 × 1086 | 4열 × 3행 | 황연청·목청완·매설영 이동, 각 4프레임 |
| `run-b.png` | 1448 × 1086 | 4열 × 3행 | 한소운·정요란·아영 이동, 각 4프레임 |
| `cast-a.png` | 1448 × 1086 | 4열 × 3행 | 첫 3명 등장/시전, 각 4프레임 |
| `cast-b.png` | 1448 × 1086 | 4열 × 3행 | 뒤 3명 등장/시전, 각 4프레임 |
| `skill-<id>.png` 6개 | 1774 × 887 | 6열 × 3행 | 영웅별 발동 6 + 진행 6 + 명중 6프레임 |

영웅당 27장, 합계 **162장 분량 / PNG 11개**입니다. 초상은 불투명 배경, 이동·시전은 실제 알파 채널, 기술은 기존 효과와 같은 검은 배경의 `screen` 합성용 원화입니다. 검은 배경을 불투명하게 일반 합성하면 안 됩니다.

기술 시트의 셀은 약 295.667px입니다. 256px 또는 296px의 고정 간격으로 자르지 마세요. 열 경계는 `round(column * width / 6)`, 행 경계는 `round(row * height / 3)`를 사용합니다. 생성된 PNG를 늘리거나 잘라 다시 저장하지 않았습니다. 기계 판독용 크기·순서·합성 방식은 `catalog.json`에 기록했습니다.

## 재생 가이드

- 모든 행은 왼쪽에서 오른쪽으로 재생합니다. 이동 4프레임은 반복입니다.
- 시전은 준비 → 무기 들기/당기기 → 발동 → 복귀의 4프레임이며 1회 재생합니다.
- 기술 0행은 발동, 1행은 진행, 2행은 명중입니다. 발동과 명중은 1회 재생합니다.
- 황연청·목청완·정요란·아영의 진행 행은 발사체 반복용입니다. 매설영·한소운은 1회 전개하는 채찍/검격 궤적입니다.
- 검수 페이지는 동작 8fps, 효과 12fps로 각 행을 개별 재생합니다. 이 값은 게임 밸런스나 확정 스킬 타이밍이 아닙니다.
- `cast-b`는 검 끝 여백을 확보하도록 보정한 시트입니다. 검수 페이지에서는 기존 이동과 몸 크기를 맞추기 위해 1.15배로 표시합니다. 전투 연결 시 최종 무기 궤적·발 기준점·몸 크기를 함께 맞춰야 합니다.
- 이번 원화의 기본 이동은 달리기/경공입니다. 비검 탑승이나 지상/공중 게임 판정을 새로 확정하지 않습니다.

## 검수 페이지

프로젝트 루트에서 다음 명령으로 이미지를 내장한 오프라인 HTML을 만듭니다.

```sh
node tools/build-heroine-gallery.mjs
# 다른 저장 위치
node tools/build-heroine-gallery.mjs /absolute/path/heroine-art-gallery.html
```

기본 출력은 `/workspace/artifacts/heroine-art-gallery.html`입니다. 기존 풍운객과 같은 표시 크기 비교, 6명 초상, 이동·시전·기술 각 행, 밝기별 배경, 속도 변경, 일시정지·한 프레임 이동과 원본 시트 보기를 제공합니다. 원본 PNG를 수정하지 않고 캔버스에서 셀을 표시합니다.

검수: 162개 셀 비어 있지 않음, 동작 시트의 투명 채널과 바깥 경계, HTML 이미지 11개 로드, 6명 카드, 정지·프레임 이동·배경 변경, 모바일 가로 넘침 없음, 브라우저 실행 오류 없음. `npm run typecheck`, `npm run build:single` 통과. 실제 전투에서의 판독성·이펙트 밀도·시전 동기화 검수는 게임 연결 후 진행해야 합니다.
