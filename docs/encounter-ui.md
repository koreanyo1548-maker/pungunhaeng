# 만남 화면: 보상과 의뢰

현재 게임 화면을 바탕으로 합의한 좌우 선택 시안을 적용했다. 기존 인연/행인 초상화와 청록 패널을 사용한다. 제목은 `강호의 만남`, 안내는 한 줄로 줄이고, 인물은 112×130px로 확대했다. 높이가 620px 이하인 게임 영역에서는 92×108px로 조정해 선택 버튼을 유지한다.

인물 아래 두 선택지는 항상 좌우로 배치한다. 각 카드에서 성공 보상 그림·이름·효과 → 수행 조건·목표 수치·제한 시간 → 선택 즉시 받는 정·사/호감도 → 선택 버튼 순서로 표시한다. 무공은 기존 무공 아이콘, 엽전은 기존 엽전 그림, 점수 두 배는 기존 배율 아이템 그림을 재사용한다. 보상·효과·제한 시간은 기존 게임 함수와 데이터에서 읽는다. #54 기준 점수 두 배 기본 지속 시간은 5초이며 장비 효과도 실제 보상 계산을 따른다.

확률과 정·사 규칙, 의뢰 실패 설명은 `정·사와 만남 규칙 보기`를 펼쳐 확인한다. 거스르기 대사는 넓은 화면에서 카드에 보조 문구로 표시하며, 작은 화면에서도 접힌 규칙 안에서 읽을 수 있다. 선택은 하단 버튼으로만 실행한다.

의뢰 생성·보상·정·사·호감도·난수·만남 타이밍과 전투 HUD 배치는 변경하지 않는다. 만남 전용 스타일은 다른 선택/편대 화면에 넘어가지 않도록 초기화한다. 이번 사용자 요청으로 Codex가 UI 코드 연결까지 수행했다.

검사: `CHROMIUM_PATH=/usr/bin/chromium node tests/e2e/encounter-ui.mjs`. 360×640·390×844·1280×900에서 모든 인연의 진행 단계별 보상·목표, 행인 보상, 좌우 배치·버튼 접근·그림 로딩·선택 결과·화면 전환을 확인한다. 캡처와 단일 HTML은 대화로 공유한다.
