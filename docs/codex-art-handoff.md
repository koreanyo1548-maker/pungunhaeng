# Codex 전달: 판 기준 개편에 필요한 아트

[판 밸런스 기준](balance-baseline.md)(드래곤플라이트 기준 개편)에 따라 그림과 연출이 더 필요하다. 규칙과 수치는 Claude가 먼저 넣고, 그림이 없는 곳은 아래 "지금 대신 쓰는 것"으로 버틴다. Codex는 이 목록을 받아 그림·연출을 만들고 연결한다(작업 범위: [작업 규칙](workflow.md) 7장).

공통:
- 그림 방향과 검수 순서는 Codex의 [풍운행 아트 스타일 기준](art-style-reference.md)을 따른다. 등급 식별, 상자·보석 재질, 실제 전투 크기 검수가 거기 있다.
- 화면은 480×800이고 크기는 그 기준 px이다. 원본은 `art/originals/`에 PNG로 두고 `python tools/convert-webp.py`로 WebP를 만든다(새 이미지는 `tools/mobile-image-profile.json`에 크기 결정을 추가).
- 이미 끝난 것: 자석·점수 두 배 드롭 아이콘(PR #31).

## 1. 적 등급 5·6

- **왜**: 판마다 등급 1~6을 순서대로 올라간다(등급 사다리). 지금 적 그림은 4등급까지다.
- **지금 대신 쓰는 것**: 4등급 그림에 색을 입혀 5·6등급을 구분한다(5등급 붉은색, 6등급 보라색, `src/render/placeholder-art.ts`의 `tinted`).
- **필요한 것**: 땅 스테이지 적 2종(`mobs.png`, 지금 4×2 아틀라스: 등급 4개 × 자세 2개)과 하늘 스테이지 적 2종(`sky-enemies.png`·`sky-enemies-motion.png`, 지금 3등급). 등급이 오를수록 더 위협적으로 보이게. 표시 크기는 지금 등급 크기(80·90·100·112px)를 이어 약 120·128px.
- **연결 위치**: `src/render/enemy-art.ts`의 `enemyArt`, 데이터는 `src/data/enemies.ts`의 `RANKS`.
- **체력바**: 등급이 높을수록 오래 버티므로 적마다 체력바가 잘 보여야 한다(DF는 모든 적 아래에 체력바).

## 2. 보물상자 적

- **왜**: 줄의 한 칸에 드물게(판당 평균 2번) 섞여 나오는 특수 적. 강한 적만큼 단단하고, 터지면 보석이 쏟아진다.
- **지금 대신 쓰는 것**: 코드로 그린 나무 상자(금속 띠와 자물쇠, 96×84, `placeholder-art.ts`의 `chestArt`).
- **필요한 것**: 평소 모습, 맞을 때 흰 번쩍임, 터지는 연출. 크기는 적 한 칸(약 90~100px).
- **연결 위치**: `src/render/enemy-art.ts`(적 그림), 터지는 연출은 `src/render/fx.ts`나 `src/render/pfx.ts`.

## 3. 보석

- **왜**: 보물상자에서 약 10개가 사방으로 튀어 떨어진다. 하나 먹으면 엽전 5개.
- **지금 대신 쓰는 것**: 코드로 그린 붉은 보석 도형(약 26px, `placeholder-art.ts`의 `drawGem`).
- **필요한 것**: 엽전(그림 30px)과 나란히 놓아도 구분되는 보석 그림(엽전보다 조금 크게), 반짝임. 먹을 때 효과(엽전보다 크게). 자석·점수 두 배 그림은 56px, 무아지경은 58px로 그려진다.
- **연결 위치**: `src/render/projectiles.ts`의 `drawPickup`.

## 4. 무아지경 끝의 화면 폭발과 엽전 비

- **왜**: 현재 무아지경 기본 지속 시간은 3초다. 끝날 때 화면 전체가 폭발하고 남은 적이 엽전으로 바뀌어 쏟아지는 것이 보상의 정점이다(DF의 HYPER FLIGHT 마무리).
- **지금 대신 쓰는 것**: 화면 번쩍임(`G.flash`), 흔들림, 큰 원형 파동, 남은 적이 엽전으로 바뀜(`src/entities/enemies.ts`의 `hyperFinish`).
- **필요한 것**: 화면 전체를 덮는 폭발(밝은 섬광에서 번지는 원), 적이 엽전으로 바뀌는 순간의 효과. 질주 중 영웅의 돌진 연출도 지금보다 강하게(DF는 영웅 주변 금빛 기운과 "HYPER FLIGHT" 글자).
- **연결 위치**: 무아지경 처리는 `src/entities/pickups.ts`의 `collect`, 그리기는 `src/render/`.

## 5. 운석 경고

- **왜**: 운석이 6초마다에서 평균 30초마다 나오는 이벤트로 바뀌고, 경고가 2초로 길어진다.
- **지금 대신 쓰는 것**: 지금의 깜빡이는 경고 표시(`src/render/renderer.ts`, `h.warn`).
- **필요한 것**: 떨어질 자리 위쪽의 경고 표식과 화면을 세로로 가르는 경고선. 2초 동안 점점 급해지는 깜빡임.

## 6. 빨라지는 판의 배경

- **왜**: 판이 3분에 걸쳐 2배 빨라진다. 배경 흐름도 같은 비율로 빨라진다(코드는 Claude가 맞춤).
- **확인할 것**: 배경 이음매나 반복 무늬가 2배 속도에서도 어색하지 않은지.

## 남는 것

- 무아지경 질주 효과의 강도와 화면 전체 폭발의 크기는 Claude의 규칙 작업 뒤 실제 화면에서 함께 맞춘다.
