# 여성 영웅 6명 연결

총 영웅 12명. 기존 전투 HUD·버튼·플레이 영역과 기본 체력 1, 전투불능 자동 교체 규칙을 유지합니다. 신규 6명은 지상 적성이며 하늘 길에서는 특성 미발동, 기존 지상 영웅의 보조 비검 표시를 따릅니다.

## 전투 역할

수치는 성급 1 기준이며 L은 성급−1(0~4), D는 기존 `shotPower() × 1.8`, m은 일반/자동 교체 1, 제때 교체 2입니다.

| 영웅 | 특성 | 교체 기술 |
| --- | --- | --- |
| 황연청 | 공격 속도 +12+2L%, 충전 +15+3L% | 탄지비침: 7발 확산, 발당 2D×m×(1+0.1L) |
| 목청완 | 공격력 +20+4L% | 회마관창: 직선 관통 1발, 10D×m×(1+0.1L) |
| 매설영 | 스침 판정 +25+4L%, 공격력 +10+2L% | 음풍편: 전방 90px, 반경 145px, 7D×m×(1+0.1L) |
| 한소운 | 공격 속도 +20+3L% | 쌍연참: 전방 105px, 반경 115px, 0.18초 간격 2회, 회당 3.5D×m×(1+0.1L) |
| 정요란 | 충전 +30+5L% | 정심반격: 주변 탄 제거 후 직선 관통, 5D×m×(1+0.1L) |
| 아영 | 공격력 +15+3L%, 공격 속도 +8+L% | 삼연시: 전방 가까운 적을 조준해 0.12초 간격 3발, 발당 4D×m×(1+0.1L) |

기본 공격의 수·충돌 크기·무기 단계 구조는 기존 방식이며 그림만 영웅별로 연결합니다. 신규 특성에 지정된 공격 속도·위력 배율은 적용됩니다. 신규 교체는 준비 동작 0.16초 후 실제 공격이 나갑니다. 연속 공격은 그 순간 위치에서 발동하며 이전 영웅의 대기 공격은 교체 시 취소됩니다. 시간 정지/일시정지에는 게임 시간과 함께 멈춥니다. 새 판의 대기 공격 목록은 초기화됩니다.

발동 원화, 진행 원화, 명중 원화는 별도 행을 사용합니다. 실제 명중에서 명중 원화를 호출합니다. 기본 공격에는 작고 잔상이 없는 전용 그림을 쓰고, 교체 투사체는 더 크게 그립니다. 동작 줄이기 설정은 기존 방식대로 정지 프레임과 약한 효과를 사용합니다.

## 저장·뽑기

영웅 목록을 기준으로 기존 저장의 새 항목을 0조각으로 채웁니다. 기존 재화·보유 영웅·성급은 보존합니다. 기본 지급 영웅은 풍운객·비천입니다. 뽑기의 영웅/인연 비율 30%/70%, 가격과 조각 성장 기준은 유지합니다. 모든 영웅이 추첨 대상인 경우 개별 영웅의 1회 뽑기 확률은 30%/12 = 2.5%이며, 최고 성급으로 제외되는 영웅 수에 따라 달라집니다.

## 확인 방법

- `node tests/e2e/heroines.mjs`: 저장 호환·도감 12명·개별 특성·시전 지연·연속 공격·실제 명중·사망 자동 교체·대기 공격 취소.
- `node tests/e2e/hero-lives.mjs`: 체력 1·기존 방어 효과·자동 교체 회귀 검사.
- `node tests/e2e/skill-art.mjs`: 기존 기술과 신규 교체, 동작 줄이기 검사.
- `npm run typecheck`, `npm run build:single`, `npm run test:e2e`, `npm run test:ui`.
- 단일 HTML을 일반 실행하면 정식 해금 규칙. `#debug&roster`로 실행하면 전체 영웅·인연을 체험할 수 있습니다.

장기 밸런스는 추가 플레이가 필요합니다. 기존 영웅의 교체 위력 범위에 맞춘 초기 수치이며, 6명 추가로 지상/공중 영웅 수는 9/3이 됩니다.
