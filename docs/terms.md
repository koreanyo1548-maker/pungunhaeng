# 화면 용어

화면에 보이는 시스템 용어는 쉬운 게임 용어로 통일한다. 무협 느낌은 고유명사(인물, 장소, 기술 이름)와 일부 장면 이름에만 남긴다. 같은 것은 한 단어로 부르고, 영어 단어 대신 우리말을 쓴다.

내부 코드의 키와 상태 값(`blast`, `charge`, `yu`/`gang`/`gi`, `성취`/`미달` 등)은 그대로 두고 표시만 바꾼다.
