# 만남 화면: 보상과 의뢰

현재 만남은 의뢰 카드 한 장을 표시한다(#58). 기존 인연/행인 초상화와 청록 패널, 확대된 인물 그림을 사용한다. 카드에서 성공 보상 그림·이름·효과, 수행 조건·목표 수치·제한 시간, 수락 시 정·사 효과를 확인한다.

선택 버튼은 없으며 화면을 누르거나 10초 카운트다운이 끝나면 의뢰를 받는다. `정·사와 만남 규칙 보기` 안을 눌러도 수락되지 않는다. 의뢰 제한 시간은 수락 후 60초다.

인연은 발사체 기술 1단계, 대표 기술 2단계, 이후 엽전 50냥을 보상으로 준다. 호감도 +1은 수락할 때가 아니라 성공할 때 받는다. 행인은 적 처치 → 엽전 50냥 하나만 제공한다. 행인의 점수 두 배 의뢰와 거스르기 선택은 제거됐다.

수동 화면 테스트 코드:

- `tests/e2e/encounter-ui.mjs`: 단일 카드, 인연 2단계와 최고 단계 보상, 행인 엽전, 화면 터치·10초 수락, 규칙 펼치기, 성공 시 호감도 기준.
- `tests/e2e/ambient-art.mjs`: 행인 초상·감사 표정과 단일 의뢰 수락 기준.
- `tests/e2e/mobile-ui.mjs`: 선택 버튼 대신 의뢰 한 장과 카운트다운, 화면 터치 기준.

이번 정리는 최신 규칙에 맞춘 테스트 코드·문서 수정이다. 사용자 요청에 따라 테스트·빌드·형식/타입 검사는 실행하지 않았다.
