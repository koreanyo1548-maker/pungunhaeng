# 슬라임 전투 리소스

사용자가 승인한 전투 시안의 캐릭터·일반 적·기본탄·배경을 적용한다.
새 캐릭터는 기존 풍운객 슬롯의 전투 외형이며 이름·초상화·능력은 그대로다.

## 마녀 디자인 적용

사용자가 승인한 마녀 뒷모습 시안을 기준으로 플레이어 4프레임을 교체했다.
큰 아이보리 모자, 보라·금색 리본과 슬라임 배지, 하늘색 머리카락, 유리구슬
지팡이, 털 장식이 있는 보라·아이보리 복식과 작은 허리 주머니를 유지한다.
탑승 슬라임도 뒤에서 보므로 등에 얼굴을 그리지 않는다.

모자 끝·머리카락·옷자락과 슬라임의 팽창·눌림이 네 프레임에서 달라진다.
기존 272px 셀, 114×114px 표시 크기, 5fps 재생과 기존 게임 코드를 그대로 사용한다.
이번 교체는 플레이어 시트만 대상이며, 일반 적·탄·배경·UI·초상화는 변경하지 않는다.

## 제작 경로

- 원화와 동작 프레임: Codex 내장 `image_gen` (`art_source: host_image`).
- 영상 생성은 사용하지 않았다. 이미지 모델로 서로 다른 4동작을 제작했다.
- 원본 생성 시트: `hero-generated.png`, `enemies-generated.png`.
- 생성 지시: `hero-prompt.txt`, `enemy-prompt.txt`.
- 후처리: vendored Agent Sprite Forge 0.6.0 `generate2dsprite.py process`.
- 처리 기록: `hero-processing.json`, `enemy-processing.json`. 최종 두 시트의 QA는 `pass`.
- 모델의 정확한 버전과 API 비용은 호스트 도구가 제공하지 않아 기록하지 않는다.

## 시트와 재생

| 런타임 원본 (`art/originals/slime-battle/`) | 배열 | 재생 / 표시 |
| --- | --- | --- |
| `hero-hover.png` | 4열 × 1행, 272px 셀 | 5fps 반복, 114×114px 표시 |
| `bat-wings.png` | 4열 × 6행, 256px 셀 | 등급별 한 행, 7fps 반복, 모두 96×96px 표시 |
| `shot.png` | 단일 256px 이미지 | 풍운객 기본탄만 80×80px 표시 |
| `world.png` | 단일 배경 | 480px 너비, 상단 6% 중첩 페이드, 기존 스크롤 속도 |

캐릭터의 네 포즈는 중립 → 슬라임 팽창·옷자락 상승 → 하강 → 눌림이다.
적은 중간 → 날개 올림 → 펼침 → 날개 내림이며, 몸통의 크기는 공통이다.
1~6등급은 붉은색·청록색·보라색·금색·붉은 왕관·보라 왕관으로 구분한다.
동작 줄이기 설정에서는 첫 프레임으로 고정한다.

## 처리 규약

캐릭터 생성 시트는 2×2, 적 생성 시트는 4×6이다. 배경 알파가 0인 픽셀에
색 정보가 남아 있어 이미지 뷰어에 따라 배경이 보일 수 있지만 런타임에서는 투명하다.
후처리는 `native_alpha`, `alpha-hygiene both`, `lanczos`, `shared-scale`,
`scale-strategy fit`, `align center`를 사용했다. 캐릭터는 `fit-scale 0.90`,
적은 `0.94`. 캐릭터 시트 경계는 `grid-rounding nearest`로 읽는다.

적 생성 시트의 일부 날개 끝이 셀 경계를 넘었다. 최초 처리의
`source_edge_touch_frames` 경고를 해결하기 위해 연결된 24개 실루엣을
분리하고 각 실루엣 주위의 알파 픽셀을 해당 개체에 배정해 320px 셀로 다시
배치했다. 날개를 자르거나 가장 큰 조각만 남기지 않았다. 패딩된 시트를
다시 처리한 최종 결과에는 원본/출력 경계 접촉·빈 프레임·클램핑 경고가 없다.

풍운객 몸체의 빨간 띠·검을 타는 그림·기본 공격 검호·옛 교대 포즈는 새 외형에
겹치지 않도록 표시만 조정했다. 다른 캐릭터와 기술의 동작은 유지한다.
일반 적의 실제 충돌 반경과 게임 상태의 크기는 그대로 두고 렌더러의 표시만 통일했다.
피격 실루엣과 격파 잔상도 해당 등급·프레임을 공유한다.

## 범위

UI·초상화·명칭·보스·정예 적·장비·아이템·전투 규칙은 교체하지 않는다.
세 이동 구간은 이번 시안 배경을 공통 사용한다. 구간별 독립 배경과 추가 동작은
이번 리소스 묶음에 포함하지 않는다.
